### ✅ 전부 끝났다 (2026-09-04)

### `www`는 왜 안 넣나

GitHub Pages 설정 화면에 노란 경고가 뜬다:

> ⚠️ www.korea-street.com is improperly configured — Domain's DNS record could not be
> retrieved. (InvalidDNSError)

**이건 잘못됐다는 말이 아니라 "없다"는 말이다.** 애초에 `www` CNAME을 등록한 적이
없고, 확인해 보면 그대로 나온다:

```
A 레코드   ✅ 185.199.108~111.153 넷 다
www        ⬜ 없음
```

우리 주소인 `korea-street.com`은 GitHub이 **「DNS valid for primary」**로 초록
확인을 준다. 즉 **앱은 멀쩡히 돌아간다.** 손님이 습관적으로 `www.`를 붙여 칠 때만
안 열리는데, 손님은 링크를 눌러 들어오지 주소를 손으로 치지 않는다.

넣고 싶어지면 가비아 DNS에 한 줄이면 된다 — 호스트 `www` → 값 `pyoseongo-hub.github.io`.

### Enforce HTTPS — 켠 것이 실제로 먹는지 확인했다

체크박스를 켰다는 말만 믿지 않고 러너에서 직접 열어 봤다:

```
http://korea-street.com   →  HTTP 301  →  https://korea-street.com/
https://korea-street.com  →  HTTP 200
```

`http`로 들어와도 자동으로 `https`로 넘겨 준다.

### 네이버 지도 — 등록한 주소 세 개

console.ncloud.com → Maps → Application → `k-street` → ⋯ → 수정 →
**Web 서비스 URL**:

```
https://pyoseongo-hub.github.io     ← 옛 주소. 지우지 않는다
http://localhost:5173               ← 개발용
https://korea-street.com            ← 2026-09-04에 추가
```

🚨 **목록에 보이는 것만으로는 저장이 아니다.** 오른쪽 아래 「✓ 저장」을 눌러야 반영된다.

⚠️ **이건 기계로 확인할 수 없다.** 네이버 지도 열쇠는 브라우저에서 그 도메인으로
불러야 검사되므로, **폰에서 앱을 열고 '내 위치'를 눌러 보는 것이 유일한 확인**이다.
안 되면 이 화면으로 돌아와 주소가 저장돼 있는지 다시 본다.

**2026-09-04 04:48 확인 결과** (「Check live site」):

```
첫 화면 200 · 파일 /assets/… 둘 다 200 · og 주소 korea-street.com · 카드 그림 열림
start_url "/" · scope "/" · 옛 주소 → 301 → korea-street.com
✅ 새 주소가 제대로 서비스되고 있다
```

**확인 도구** — Actions에서 언제든 다시 돌릴 수 있다:
- 「Check DNS」 — 도메인이 GitHub을 가리키나
- 「Check live site」 — 새 주소가 제대로 뜨나 (파일·미리보기 카드·설치 정보·옛 주소 넘김)

### 겪은 것 — 배포가 겹치면 앞 것이 취소된다

도메인 전환 커밋을 올린 직후에 다른 커밋을 올렸더니, deploy.yml 의
`concurrency: cancel-in-progress` 때문에 **앞 배포가 취소됐다.** 뒤 배포에 모든
변경이 들어 있어 결과는 같지만, 그 사이 몇 분 동안 **옛 화면이 그대로 서비스된다.**
도메인을 바꾸는 날에는 커밋을 몰아서 하지 말고 **하나 올리고 배포가 끝날 때까지 기다릴 것.**


## 어떻게 여기까지 왔나 (같은 길을 다시 걷지 않게)

| 후보 | 결과 | 어떻게 확인했나 |

🚨 **교훈 — 도메인은 "등록가능"이라는 말만 듣고 진행하지 않는다.**
한 번 `k-street.com`으로 정하고 문서까지 적었다가 되돌렸다. 전해 들은 말이
틀렸던 것이다. 이제는 `scripts/check-domains.mjs`(Actions의 「Check domains」)로
**기계가 직접 whois를 물어보고**, 마지막에 **등록 사이트 화면**으로 값까지 본다.

## 왜 이 주소인가

- **`.com`인 이유** — 외국인은 주소를 모르면 습관적으로 `.com`을 붙인다. 우리 손님은
  미국·일본·유럽·동남아 사람들이고 그들에게 `.kr`은 낯선 꼬리표다.
- **`k` 대신 `korea` 인 이유** (사용자 지시) — `k-street.com`이 이미 남의 것이었고,
  주소에 `korea`가 박히면 검색에서도 잡히고 무엇을 하는 곳인지 한눈에 보인다.
- **하이픈이 있는 이유** — 붙여 쓴 `koreastreet.com`은 2008년부터 남이 갖고 있다.
  그리고 하이픈은 앱 이름(`K-STREET`)의 표기와도 결이 같다.
- **앱 이름을 안 바꾸는 이유** (사용자 결정: "이름은 그대로") —
  `K-Street`가 짧고 K-pop·K-food 계열로 읽혀 브랜드로 낫다. 주소가 `korea-street.com`
  이면 **검색에서 "korea"까지 잡히므로 둘 다 얻는다.** 이름과 주소가 조금 다른 것은
  흔한 일이고, 앱 안은 아무것도 안 바뀐다.

## 🚨 순서를 지킬 것 — 거꾸로 하면 사이트가 죽는다

**DNS가 먼저, GitHub 설정이 나중이다.** GitHub에 도메인을 먼저 적으면 github.io 주소가
새 도메인으로 넘겨지는데, 그 도메인이 아직 아무 데도 안 닿으므로 **사이트가 통째로
안 열린다.**

### 1단계 — 도메인 산다 (사장님)

가비아에서 `korea-street.com` 결제(19,800원). 1년이면 충분하다(자동 연장은 켜 둘 것 — 만료되면
주소를 남이 채 간다).

### 2단계 — DNS를 GitHub 쪽으로 돌린다 (사장님)

가비아 → **My가비아 → 도메인 → DNS 관리 → DNS 설정**

**A 레코드 4개**를 추가한다(호스트는 비워 두거나 `@`):

```
185.199.108.153
185.199.109.153
185.199.110.153
185.199.111.153
```

**AAAA 레코드 4개**도 같이 넣으면 좋다(IPv6 — 없어도 되지만 넣는 편이 빠르다):

```
2606:50c0:8000::153
2606:50c0:8001::153
2606:50c0:8002::153
2606:50c0:8003::153
```

`www`로도 들어오게 하려면 **CNAME** 하나 더: 호스트 `www` → 값 `pyoseongo-hub.github.io`

⏳ 반영에 **10분~1시간** 걸린다. 바로 안 되어도 정상이다.

### 3단계 — GitHub에 도메인을 알려 준다 (사장님)

저장소 → **Settings → Pages → Custom domain** 에 `korea-street.com` 입력 → Save.

- GitHub이 DNS를 확인하고 초록 체크를 준다. 빨간 글씨가 뜨면 2단계가 아직 안 퍼진 것이니
  조금 기다렸다 새로고침한다.
- **Enforce HTTPS**는 인증서가 발급된 뒤에 켤 수 있다(보통 몇 분~몇 시간).
  체크가 회색이면 아직 발급 중이다 — 나중에 다시 와서 켠다.

### 4단계 — 코드를 새 주소에 맞춘다 (Claude)

⚠️ **3단계와 거의 동시에 해야 한다.** 지금 앱은 `/k-street/` 하위 경로를 기준으로
빌드돼 있는데, 도메인을 붙이면 사이트가 **주소의 최상단**으로 옮겨진다. 그 사이에는
파일을 못 찾아 화면이 깨진다(몇 분 정도 — 아직 손님이 없어서 괜찮다).

고칠 곳:

| 파일 | 무엇을 |
|---|---|
| `vite.config.ts` | `base: '/k-street/'` → `base: '/'` |
| `vite.config.ts` (manifest) | `start_url`·`scope` 도 `/k-street/` → `/` |
| `index.html` | `og:url`·`og:image`를 `https://korea-street.com/…` 로 |
| `public/CNAME` | GitHub이 3단계에서 자동으로 만들지만, 없으면 `korea-street.com` 한 줄로 만든다 |

### 5단계 — 네이버 지도 콘솔에 새 주소를 넣는다 (사장님)

**안 하면 새 주소에서 '내 위치'가 안 된다.**

console.ncloud.com → Maps → Application → `k-street` 의 ⋮ → 수정 →
**Web 서비스 URL**에 `https://korea-street.com` **추가**(기존 github.io 주소는 남겨 둔다 —
당분간 옛 주소로 들어오는 사람이 있다).

### 6단계 — 확인 (Claude)

- `https://korea-street.com` 이 열리는가
- 사진·글꼴·길찾기가 다 되는가
- 공유 카드가 뜨는가 (카톡에 링크를 붙여 보면 바로 보인다)
- 옛 주소(`pyoseongo-hub.github.io/k-street/`)가 새 주소로 넘어가는가
