# 🌐 도메인 연결하기

⚠️ **어느 주소로 갈지 아직 안 정해졌다 (2026-09-04 오후 기준).**

한 번 `k-street.com`으로 정했다가 되돌렸다 — 가비아 화면을 직접 보니
**「이미 등록된 도메인」**이었다. 확인이 엇갈렸던 것이다.

🚨 **교훈: 도메인은 "등록가능"이라는 말만 듣고 진행하지 않는다.**
화면 캡처로 눈으로 보고 나서 정한다. 아래 표는 **화면으로 확인된 것만** 적는다.

| 후보 | 상태 | 확인 |
|---|---|---|
| `kstreet.com` | ❌ 남이 쓰는 중 | 검색으로 확인 (K Street Consulting 등 DC 회사들) |
| `k-street.com` | ❌ **이미 등록됨** | **가비아 화면 캡처로 확인** |
| `k-street.kr` | ❓ 다시 확인 필요 | 말로만 들었고 화면을 못 봤다 |

아래 연결 절차 자체는 **어느 주소로 정해지든 그대로 쓴다** — 주소 이름만 바꿔 읽으면 된다.

## 주소를 고르는 기준 (정해지면 위 표를 갱신할 것)

- **`.com`이 나은 이유** — 외국인은 주소를 모르면 습관적으로 `.com`을 붙인다. 우리 손님은
  미국·일본·유럽·동남아 사람들이고 그들에게 `.kr`은 낯선 꼬리표다.
  "한국 서비스"라는 신호는 **이름(K-Street)이 이미 하고 있어서** 주소까지 할 필요가 없다.
- **하이픈을 넣은 이유** (사용자 지적) — 붙여 쓴 `kstreet`는 영어권에서 워싱턴 DC의
  로비 업계("K Street")로 읽힐 여지가 남는다. 하이픈이 들어가면 **K-pop · K-food와 같은
  모양**이 되어 "K- + street"로 읽힌다. 앱에 찍힌 이름(`K-STREET`)과도 표기가 같다.

## 🚨 순서를 지킬 것 — 거꾸로 하면 사이트가 죽는다

**DNS가 먼저, GitHub 설정이 나중이다.** GitHub에 도메인을 먼저 적으면 github.io 주소가
새 도메인으로 넘겨지는데, 그 도메인이 아직 아무 데도 안 닿으므로 **사이트가 통째로
안 열린다.**

### 1단계 — 도메인 산다 (사장님)

가비아에서 `k-street.com` 결제. 1년이면 충분하다(자동 연장은 켜 둘 것 — 만료되면
주소를 남이 채 간다).

### 2단계 — DNS를 GitHub 쪽으로 돌린다 (사장님)

가비아 → **My가비아 → 도메인 → DNS 관리 → DNS 설정**

**A 레코드 4개**를 추가한다(호스트는 비워 두거나 `@`):

```
185.199.108.153
185.199.109.153
185.199.110.153
185.199.111.153
```

**AAAA 레코드 4개**도 같이 넣으면 좋다(IPv6 — 없어도 되지만 넣는 편이 빠르다):

```
2606:50c0:8000::153
2606:50c0:8001::153
2606:50c0:8002::153
2606:50c0:8003::153
```

`www`로도 들어오게 하려면 **CNAME** 하나 더: 호스트 `www` → 값 `pyoseongo-hub.github.io`

⏳ 반영에 **10분~1시간** 걸린다. 바로 안 되어도 정상이다.

### 3단계 — GitHub에 도메인을 알려 준다 (사장님)

저장소 → **Settings → Pages → Custom domain** 에 `k-street.com` 입력 → Save.

- GitHub이 DNS를 확인하고 초록 체크를 준다. 빨간 글씨가 뜨면 2단계가 아직 안 퍼진 것이니
  조금 기다렸다 새로고침한다.
- **Enforce HTTPS**는 인증서가 발급된 뒤에 켤 수 있다(보통 몇 분~몇 시간).
  체크가 회색이면 아직 발급 중이다 — 나중에 다시 와서 켠다.

### 4단계 — 코드를 새 주소에 맞춘다 (Claude)

⚠️ **3단계와 거의 동시에 해야 한다.** 지금 앱은 `/k-street/` 하위 경로를 기준으로
빌드돼 있는데, 도메인을 붙이면 사이트가 **주소의 최상단**으로 옮겨진다. 그 사이에는
파일을 못 찾아 화면이 깨진다(몇 분 정도 — 아직 손님이 없어서 괜찮다).

고칠 곳:

| 파일 | 무엇을 |
|---|---|
| `vite.config.ts` | `base: '/k-street/'` → `base: '/'` |
| `vite.config.ts` (manifest) | `start_url`·`scope` 도 `/k-street/` → `/` |
| `index.html` | `og:url`·`og:image`를 `https://k-street.com/…` 로 |
| `public/CNAME` | GitHub이 3단계에서 자동으로 만들지만, 없으면 `k-street.com` 한 줄로 만든다 |

### 5단계 — 네이버 지도 콘솔에 새 주소를 넣는다 (사장님)

**안 하면 새 주소에서 '내 위치'가 안 된다.**

console.ncloud.com → Maps → Application → `k-street` 의 ⋮ → 수정 →
**Web 서비스 URL**에 `https://k-street.com` **추가**(기존 github.io 주소는 남겨 둔다 —
당분간 옛 주소로 들어오는 사람이 있다).

### 6단계 — 확인 (Claude)

- `https://k-street.com` 이 열리는가
- 사진·글꼴·길찾기가 다 되는가
- 공유 카드가 뜨는가 (카톡에 링크를 붙여 보면 바로 보인다)
- 옛 주소(`pyoseongo-hub.github.io/k-street/`)가 새 주소로 넘어가는가

결제 카드가 바뀌면 잊지 말고 갱신할 것. 연 1.5만원 안팎이다.
