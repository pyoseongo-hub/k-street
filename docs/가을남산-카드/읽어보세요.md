## 📐 왜 이렇게 생겼나

**사진 띠 1080×900 (6:5).** 고른 넷이 세로 둘·가로 둘이라 각자 비율대로 두면
넘길 때 들쭉날쭉하다. **4:5 로 자르면 3번의 남산타워가 잘려 나간다** —
6:5 는 가로 사진에서 폭을 256px 만 깎아 타워와 억새가 둘 다 산다.
어디를 남길지는 스크립트의 `focus` 가 정한다.

**잘라 둔 사진은 저장소에 없다.** 브라우저가 `object-position` 으로 그때그때 자른다
(PNG 로 넣으면 6.6MB 가 는다). 원본만 있으면 언제든 다시 나온다.

**JPEG 로 낸다.** PNG 는 사진에 안 맞는 꼴이라 한 장이 1.9MB 였다 — 12장 20MB.
품질 88 이면 눈으로 구별이 안 되면서 **3.7MB** 로 떨어진다.

**중·일 반반은 사장님이 만드신 것이다.** 영어 4번 카드의 **빈 오른쪽**을
동그라미 치시며 *"텍스트 중국어 일어 반반"* 이라고 하셨다.
