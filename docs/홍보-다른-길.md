> External links should point to **primary sources** … should **not** include links to
> secondary sources such as media, blogs, map services or **other travel guides**.

우리가 바로 그 **other travel guides** 다. 넣어도 지워지고, 계정만 상한다.
**같은 이유로 위키백과도 안 된다.**

**둘 다 붙였다. 쓰임이 다르기 때문에 둘 다 필요하다:**

| | 어디에 | 보내는 주소 | 무슨 말인가 |
|---|---|---|---|
| 🔗 **곳 하나** | 곳 카드 안, 「기사에게 보여주기」 오른쪽 | `korea-street.com/place/<슬러그>/` | **"여기 가 봐"** — 갈 곳을 이미 정한 사람에게 |
| 🏠 **앱 통째로** | 화면 맨 아래 소개 줄 밑 | `korea-street.com/` | **"이거 써 봐"** — 아직 뭘 볼지 모르는 사람에게 |

> 사장님 지적(2026-09-06): **"우리 앱을 링크 공유가없네."**
> 곳 공유만 먼저 붙였더니 **앱을 통째로 소개할 방법이 빠져 있었다.**
> 홍보로 퍼지는 건 대개 뒤쪽인데 그게 없었다.

- 폰은 `navigator.share`(카톡·문자·인스타로 바로 감), 안 되는 데선 「링크 복사」 →「복사됨」
- 받은 사람이 **앱을 안 깔아도, 자바스크립트가 안 돌아도** 열린다
- 미리보기 카드(제목·설명·사진)는 `index.html` 의 og:* 가 만들어 준다 — 따로 안 만든다
- 12개 언어 다 들어갔고, **그림 옆에 낱말을 같이** 적었다(아이콘만으로는 못 알아본다는
  지적을 두 번 받았다)

📌 앱 단추는 **두 탭 밖**에 있어서 「저장한 곳」 탭에서는 스크롤 없이 바로 보인다.
   홈은 목록이 길어 맨 끝까지 내려야 나온다 — 거기까지 본 손님이 남에게 권할 사람이다.
