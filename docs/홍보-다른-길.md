# 📣 레딧 말고 — 다른 홍보 길 (2026-09-06)

> 사장님: "레딧 말고 홍보 할 방법 찾아봐."

레딧은 **하나의 길이지 유일한 길이 아니다.** 잣대는 그대로다:
**돈을 안 쓴다 · 손님은 서울에 처음 오는 사람 · 다운로드 수가 목표가 아니다.**

---

## 🚨 먼저 고칠 것 — **공유 단추가 없다**

2026-09-06에 찾았다. 코드를 뒤져 보니 `navigator.share`도 「링크 복사」도 **없다.**

**가장 싼 홍보는 손님이 친구에게 보내는 것인데, 지금은 보낼 방법이 없다.**
곳 페이지 307장을 만들어 놨으니 **곳마다 보낼 주소는 이미 있다** —
카드에 공유 단추 하나만 붙이면 된다.

- 폰은 `navigator.share`(카톡·문자·인스타로 바로 감), 안 되는 데선 「링크 복사」
- 보내는 주소는 `korea-street.com/place/<슬러그>/` — 받은 사람이 **앱을 안 깔아도** 보인다

📌 **홍보를 늘리기 전에 이걸 먼저 한다.** 밖에서 사람을 데려와도
안에서 퍼져 나갈 구멍이 없으면 거기서 끝난다.

---

## 🥇 1. 공공데이터 활용사례 등록

**우리는 한국관광공사 자료를 쓰고 출처를 밝히고 있다.** 그게 그대로 자격이 된다.

- 공공데이터포털에 **활용사례**를 등록할 수 있고, 사장님은 **이미 계정과 인증키**가 있다
- 돈이 안 들고, **공신력**이 붙는다 — "관광공사 자료로 만든 12개 언어 무료 안내"
- 기관·언론이 사례를 찾을 때 들어오는 경로다
- 한 번 올려 두면 **계속 남는다**(레딧 글은 하루면 묻힌다)

⚠️ 절차·요건은 **확인 못 했다**(작업 세션에서 그 사이트를 못 연다).
사장님이 열어서 화면을 보여 주시면 한 단계씩 같이 한다.

## 🥈 2. 핀터레스트

**여행을 계획하는 사람이 실제로 모이는 곳**이고, 레딧과 성질이 정반대다.

| | 레딧 | 핀터레스트 |
|---|---|---|
| 수명 | 하루면 묻힌다 | **몇 달~몇 년 산다** |
| 성격 | 대화 | **검색 + 저장** |
| 우리 자산 | 글 | **사진 285곳** |

- 사진이 **공공누리 1유형**이라 쓸 수 있다(출처 표기는 유지)
- 핀 하나 = 곳 페이지 하나로 연결
- 한 번에 20~30개 만들어 두면 계속 일한다 — **혼자 하는 사람에게 맞는 방식**

## 🥉 3. 여행 포럼 — 레딧과 같은 방식, 다른 장소

트립어드바이저 포럼 같은 곳. **답을 먼저 주는** 방식은 그대로다.
레딧에서 쓴 댓글 재료를 그대로 쓸 수 있다.

⚠️ 방마다 규칙이 다르다. 들어가면 **규칙부터** 본다.

## 4. 「이번 주 서울」 한 장

`docs/다음-앱-아이디어.md`의 그것. **홍보 재료이자 검색 유입 장치**다.
매주 저절로 바뀌는 페이지는 검색·AI가 제일 좋아한다.

## 5. 게스트하우스·호스텔에 메일

**손님이 정확히 거기 있다.** 무료 도구니까 손님에게 알려 달라고.
QR 한 장이면 된다. 답장률은 낮지만 **한 곳만 걸려도 매일 새 손님**이다.

## 6. 한국 여행 블로거·유튜버에게 메일

무료·광고 없음·12개 언어는 **소개하기 좋은 소재**다.
⚠️ 한 번에 여러 명에게 같은 글을 보내지 않는다. 스팸으로 보인다.

## 순서

```
① 공유 단추 붙이기 ← 밖에서 데려오기 전에 안에서 퍼질 구멍부터
② 공공데이터 활용사례 등록 ← 한 번 하면 남는다
③ 핀터레스트 ← 사진 자산을 쓴다. 오래 산다
④ 여행 포럼 + 레딧 ← 답을 주면서 신뢰를 쌓는다 (계속)
⑤ 게스트하우스·블로거 메일 ← 위가 좀 쌓인 뒤에
```

⚠️ **한꺼번에 다 하지 않는다.** 혼자 하는 사람이 다섯 갈래를 동시에 잡으면
전부 얕아진다. 하나씩, 한 번에 하나.

## 🏘️ 커뮤니티 목록 (2026-09-06)

> 사장님: "다른 커뮤니티 찾아서 홍보."

⚠️ **아래는 전부 「확인 못 했다」.** 작업 세션에서 바깥 사이트를 못 연다.
살아 있는지·규칙이 뭔지는 **사장님이 열어 보셔야** 한다. 새 방은 **Rules 먼저.**

### A. 손님이 있는 곳 — 서울에 처음 오는 사람

| 곳 | 왜 | 주의 |
|---|---|---|
| 🥇 **Quora** | 답이 **구글 검색에 뜬다.** 한 번 쓰면 몇 년 산다. 우리 1번 채널(검색)과 **곱해진다** | AI 글 규제가 있다 — 한글 초안 → 사장님 수정 → 번역 방식 그대로 |
| 🥈 **트립어드바이저 한국/서울 포럼** | 질문에 답하는 방식이 레딧과 같다. 재료를 그대로 쓴다 | 활동량이 예전만 못할 수 있다 |
| 🥉 **페이스북 그룹** | 실제 여행 계획을 짜는 사람이 모인다 | 가입 승인·자기 홍보 규칙 |
| **디스코드** | r/koreatravel 규칙에 디스코드가 언급돼 있었다 → 실재한다 | 대화형이라 시간이 든다 |

**페이스북 그룹 찾는 법** — 페이스북 검색창에 이렇게:
```
Korea travel planning
Seoul travel tips
Korea trip
```
→ 「그룹」 칸으로 거르고, **회원 수 많고 최근 글이 있는 것**만 고른다.

### B. 손님은 아니지만 **링크를 주는 곳**

우리 1번 채널이 검색이다. 검색은 **다른 사이트가 우리를 링크할수록** 세진다.
아래는 손님을 데려오기보다 **링크를 남기는** 자리다. 하루 반짝하고 끝나지만
**링크는 남는다.**

| 곳 | 각도 |
|---|---|
| **Product Hunt** | 「무료·가입 없음·추적 없음·12개 언어」 |
| **Hacker News (Show HN)** | 개발자들이 좋아하는 각도 — 서버 없음·고정비 0원·추적 코드 0줄 |
| **Indie Hackers** | 혼자 만든 것, 광고 없이 굴리는 방식 |

⚠️ **셋 다 한 번뿐이다.** 준비 없이 쓰면 그 한 번을 버린다.
스크린샷 3장(`docs/홍보-사진/`)과 영어 소개 글(`docs/영어-소개글.md`)을 붙여서 간다.

### 순서

**Quora 하나부터.** 검색과 곱해지는 곳이라 값어치가 가장 크고,
레딧에서 쓰던 방식(질문에 답하기)을 그대로 쓸 수 있다.
거기서 통하면 트립어드바이저·페이스북으로 넓힌다.

⚠️ **동시에 여러 곳에 같은 글을 붙이지 않는다.** 그게 스팸으로 잡히는 제1원인이다.
