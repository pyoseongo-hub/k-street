# 🎙️ K-Street 공통 마무리 문안 — 사장님 확인용 (2026-09-21)

사장님 지시: *"나레이션 넣을거니 … 마지막 공통적으로 들어갈 K-Street 설명 만들어 한글로 내가 확인"*

영상·카드의 **맨 끝에 매번 똑같이** 들어가는 말이다. 앞 내용은 그때그때 달라도 여기는 안 바뀐다.
읽는 데 **7~9초**(영어로 읽었을 때 기준). 마지막 카드(korea-street.com · 출처)와 같이 뜬다.

## 안 ① — 짧게 (7초)

```
케이스트리트.
서울의 축제, 시장, 산책길을 12개 언어로.
무료, 가입 없음.
korea-street.com
```

## 안 ② — 손님 쪽에서 말하기 (8초)

```
서울에서 지금 뭘 볼지 모르겠다면,
케이스트리트에서 찾아보세요.
축제, 시장, 산책길 — 12개 언어, 무료, 가입 없음.
korea-street.com
```

## 안 ③ — 기사에게 보여 주기 강조 (9초)

```
케이스트리트.
서울의 축제와 시장, 산책길을 12개 언어로.
한국어 이름을 기사에게 그대로 보여 줄 수 있어요.
무료, 가입 없음. korea-street.com
```

## 확인해 주실 것

1. ①·②·③ 중 하나, 또는 고쳐 주신 문장 (사장님 말투로 고쳐 주셔도 됩니다 — 잠수교 때처럼)
2. 고르시면 그 문장을 **영어로 옮기고 한글 뜻을 옆에** 붙여서 다시 보여 드립니다. 확인 뒤에야 목소리로 만듭니다.

## 근거

여기 쓴 말(12개 언어 · 무료 · 가입 없음 · 축제와 시장, 산책길 · 기사에게 보여 주기)은
**전부 앱이 실제로 하는 것**이다. 숫자가 필요하면 그때 앱 자료를 다시 센다 —
**이 문서에 숫자를 적어 두지 않는다** (사장님 2026-09-22: *"팩트 자체를 저장에서 빼"*).
묵은 숫자가 문서에 남아 홍보 글로 새어 나가는 것이 이 저장소가 되풀이해 데인 자리다.
