처음에는 **with.kakao.com(제휴안내)** 와 **devtalk.kakao.com/c/affiliate/99** 를 적어 뒀다.
사장님이 실제로 열어 보고 짚어 줬다: **"여기 아닌 거 같어 / 상품에 대한 건데 전부"**.

맞았다. with.kakao.com 의 「서비스/콘텐츠 제휴」는 **선물하기 상품 입점** 폼이다 —
칸이 전부 `배송상품(패션)`·`배송상품(식품)`·`배송상품(디지털/가전)`… 이다.
물건 파는 사람용 창구다.

**더 근본적인 것을 놓치고 있었다:**

> 🚨 **카카오T와 카카오맵은 「카카오」가 아니라 「카카오모빌리티」다. 별도 회사다.**

그래서 with.kakao.com 은 애초에 갈 곳이 아니었다. 거기 아무리 잘 써서 넣어도
담당자에게 안 간다. **링크를 눌러 보지 않고 이름만 보고 적어 둔 탓이다** —
이 저장소가 지키기로 한 "확인 못 한 것은 넣지 않는다"를 내가 어겼다.

찾아보니 카카오모빌리티는 **개발자용 창구를 따로 갖고 있다**:
[developers.kakaomobility.com](https://developers.kakaomobility.com/) —
길찾기 API 같은 것을 **제휴 계약을 맺은 곳에만** 열어 준다.
우리가 묻는 종류의 이야기를 **받아 주는 창구가 실제로 있다**는 뜻이다.
