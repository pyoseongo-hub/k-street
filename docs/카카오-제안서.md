# 📮 카카오에 보낼 제안서 (초안)

**목적** — 카카오맵 길찾기 화면에서 **카카오T 택시 호출로 넘어가는 길**을 열어 달라는 것.
지금은 카카오맵이 "택시 약 39,600원"이라고 **요금까지 계산해 보여 주면서도**,
그 화면에서 택시를 부를 방법이 없다.

**🚨 보내는 것은 사장님입니다.** 저(작업 세션)는 초안만 씁니다 —
남의 창구에 사장님 이름으로 글을 올리는 일은 제가 하지 않습니다.
아래 글을 **그대로 복사해서 붙여 넣으시면** 됩니다. 고치고 싶은 곳은 고쳐도 됩니다.

**개인 개발자 이름으로 보냅니다** (사장님 결정 2026-09-04: "사업자 보낼 이유가 있나
개인으로해 개인 개발자"). 사업자를 앞세우면 제휴 심사·계약 절차로 넘어가 오래 걸립니다.
우리가 원하는 것은 계약이 아니라 **URL 스킴 하나**입니다.

## ① with.kakao.com — 제휴 안내

👉 https://with.kakao.com/

**제목**

```
카카오맵 → 카카오T 택시 호출 연결(URL 스킴) 요청 — 외국인 관광객 앱 개발자
```

**본문** (아래를 그대로 복사)

```
안녕하세요. 서울을 찾는 외국인 관광객을 위한 12개 언어 안내 웹앱
K-Street(https://korea-street.com)를 만들고 있는 개인 개발자입니다.

건의드릴 것은 한 가지입니다.
카카오맵 길찾기 화면에서 카카오T 택시 호출로 넘어가는 길을 열어 주실 수 있을까요.

■ 지금 상황

저희 앱은 장소마다 카카오맵 길찾기로 바로 넘기는 버튼을 두고 있습니다.
kakaomap://route?sp=출발&ep=도착&by=CAR 로 열면 출발지·도착지가 정확히 채워지고,
화면에 "택시 약 39,600원"이라는 예상 요금까지 나옵니다.

그런데 그 화면의 탭은 자동차 / 대중교통 / 도보 / 자전거뿐입니다.
요금을 보고 "그럼 택시를 타자"고 마음먹은 손님이, 정작 그 자리에서
택시를 부를 방법이 없습니다. 카카오T를 따로 열어 목적지를 처음부터
다시 입력해야 합니다.

한국어를 못 읽는 외국인 손님에게는 이 "다시 입력"이 사실상 벽입니다.
목적지 이름을 한글로 칠 수가 없기 때문입니다.

■ 부탁드리는 것

목적지 좌표를 받아 카카오T 택시 호출 화면을 여는 URL 스킴을 공개해 주시거나,
카카오맵 길찾기 화면에 「택시 호출」 버튼을 추가해 주시면 좋겠습니다.

예를 들어 이런 형태면 충분합니다.
  kakaot://taxi?dest_lat=37.5701653&dest_lng=126.9997218&dest_name=광장시장

■ 왜 카카오에도 이득인지

· 지금은 이 지점에서 손님이 그냥 떨어져 나갑니다. 연결만 되면 그대로 호출이 됩니다.
· 외국인 관광객은 대중교통보다 택시 이용 비율이 높은 이용자층입니다.
· 저희 같은 여행 앱들이 "택시는 카카오T"로 자연스럽게 안내하게 됩니다.
  지금은 안내할 방법이 없어 다른 선택지를 찾게 됩니다.
  (실제로 우버 딥링크도 시험해 봤는데, 앱은 열리지만 픽업·도착이
   채워지지 않아 손님에게 내놓을 수 없었습니다.)

■ 확인한 것들

혹시 제가 못 찾은 것일 수 있어 아래를 직접 눌러 확인했습니다. 모두 안 됐습니다.
  kakaot://
  kakaot://taxi
  kakaot://taxi?dest_lat=…&dest_lng=…&dest_name=…

공개된 방법이 이미 있는데 제가 못 찾은 것이라면, 그 문서 위치만 알려 주셔도
충분히 감사하겠습니다.

■ 저에 대해

개인 개발자입니다. 광고·제휴 수익 없이 만들고 있고, 식당·관광지에서
돈을 받고 노출을 올려 주지 않는 것을 원칙으로 두고 있습니다.
계약이나 제휴를 요청드리는 것이 아니라, 공개된 연결 방법 하나를
여쭙는 것입니다.

앱: https://korea-street.com
답장 주실 곳: (여기에 사장님 이메일 주소를 적어 주세요)

읽어 주셔서 감사합니다.
```
