# 🚇🧳 케이푸드에도 「가까운 역 + 짐 보관」 넣기 — 넘겨줄 설명서

**2026-09-11에 다시 씀.** K-Street에서 만들기를 끝냈으니, 그 모양 그대로 옮기면 됩니다.

🚫 **이 문서는 설명서일 뿐입니다.** K-Street 세션은 케이푸드 저장소를
건드리지 않기로 되어 있습니다(사장님 지시: "침범 안되").
그래서 코드를 짜지 않았습니다 — 이 문서를 **케이푸드 세션에 그대로 주세요.**

📋 **맨 아래 「케이푸드 세션에 붙여넣을 글」**을 복사해서 붙이시면 됩니다.

## 무엇을 만드나 — 화면 세 장

### ① 식당 카드 안 — 단추 세 개

```
[ 📍 카카오맵 ]  [ N 네이버지도 ]
[ 목적지 보여주기 ] [ 주변 먹거리 ↗ ] [ 짐 보관 ]   ← 짐 보관만 색을 준다
```

⚠️ **회색 글자 한 줄로 넣지 마세요.** K-Street가 먼저 그렇게 했다가
단추 둘 밑에 묻혀서 안 읽혔습니다. 사장님이 화면에 동그라미를 쳐서 짚어 주셨습니다.

### ② 「짐 보관」을 누르면 — 첫째 카드 (가까운 역)

```

```

## 🚨 **카드를 왜 둘로 갈랐나** — 이걸 안 지키면 사고가 납니다

또타라커와 또타러기지는 **이름이 비슷할 뿐 다른 서비스**입니다.

| | 또타라커 | 또타러기지 |
|---|---|---|
| 무엇 | 무인 보관함 | **직원이 받아 주는 곳** |
| 몇 곳 | **273개 역** | **6개 역** |
| 시간 | **05~24시** | **09~22시** |
| 크기 단위 | **cm** (칸 크기) | **인치** (가방 크기) |

한 카드에 섞어 적으면 **손님이 밤 11시에 닫힌 창구 앞에 섭니다.**
그래서 K-Street는 카드를 둘로 갈랐습니다.

## ⛔ 시작하기 전에 — 좌표부터 세세요

**좌표가 없으면 아무것도 안 됩니다.**

K-Street에서 하마터면 못 만들 뻔했습니다. 좌표가 **두 군데에 흩어져** 있었는데
한쪽만 보고 **「13%밖에 없네, 못 만들겠다」**고 접을 뻔했습니다.
합쳐 보니 **99%**였습니다.

```
· seed.js 항목에 lat/lng 가 있나?
· 따로 좌표 파일이 있나?
· 네이버 지역검색으로 받아 둔 자료에 좌표가 남아 있나?
```

**25,369곳 중 몇 %에 좌표가 있는지 숫자로 먼저 세세요.**
50% 아래면 이 기능은 반쪽이 됩니다 — 그때는 좌표부터 채우는 게 순서입니다.

## 만드는 법 — 다섯 걸음

### ① 열쇠 확인

카카오 REST 열쇠(`KAKAO_REST_API_KEY`). 없으면 developers.kakao.com 에서
무료로 즉시 발급됩니다(승인 대기 없음).

### ② 좌표를 한 군데로 모으기

흩어진 좌표를 합쳐 `{ id, name, lat, lng }` 목록 하나로.
K-Street: `scripts/dump-place-coords.ts`.
⚠️ **어디서 온 좌표인지 같이 적어 두세요.**

### ③ 곳마다 「가까운 지하철역」 묻기

역 목록이 **필요 없습니다.** 좌표를 주고 물으면 됩니다:

```
GET https://dapi.kakao.com/v2/local/search/category.json
    ?category_group_code=SW8      ← SW8 이 지하철역
    &x=<경도>&y=<위도>
    &radius=1500
    &size=1
    &sort=distance

헤더: Authorization: KakaoAK <열쇠>
```

K-Street 코드: `scripts/find-nearest-station.mjs` — 그대로 베끼면 됩니다.

🚨 **곳이 25,369개면 호출도 25,369번입니다.** K-Street(283곳)와 규모가 다릅니다.
   하루 한도를 먼저 확인하고, 도시별로 나눠 돌리고, 이미 받은 곳은 건너뛰세요.

🚨 **호출 실패와 「역이 없다」를 반드시 가르세요.** 섞으면 화면에 거짓말이 나갑니다.
   K-Street 코드는 `{ got, ok }` 두 값을 따로 돌려주는 방식으로 갈랐습니다.

### ④ 또타러기지 6곳의 역 좌표 받기 (한 번만)

지점 단추를 누르면 **길찾기**가 떠야 하는데, 좌표가 없으면 카카오·네이버는
**검색 화면**만 띄웁니다. 그래서 이 여섯 곳의 좌표가 따로 필요합니다.

🚨 **「서울역」으로 검색하면 안 됩니다.** K-Street가 여기서 틀렸습니다 —
앞글자만 같으면 받아들이게 해 뒀더니 서울역 자리에 **「서울역 GTX-A」**가
들어왔습니다. 같은 이름으로 시작하는 역이 수두룩합니다(공항철도·GTX·경의중앙선).

🔑 **호선까지 넣어서 묻고, 이름이 정확히 일치하는 것만 받으세요:**

```
질문: "서울역 1호선"   →  받은 이름이 정확히 "서울역 1호선" 인 것만 채택
질문: "홍대입구역 2호선" →  ...
```

K-Street 코드: `scripts/find-luggage-branches.mjs`.
🚨 여섯 곳을 다 못 받으면 **저장하지 마세요.** 반쪽 자료는 화면에서 한 곳을
조용히 사라지게 만듭니다.

## 🚨 절대 지킬 것 — 네 가지

### 1. **「보관함이 있습니다」라고 단정하지 마세요**

또타라커는 273개 역, 서울 지하철역은 약 340개. **대부분 있지만 전부는 아닙니다.**
「있습니다」라고 적으면 없는 역에 간 손님이 캐리어를 끌고 헛걸음합니다.
반드시 **「대부분의 역에 있습니다」**로.

### 2. **역이 없는 것도 「답」입니다 — 빈칸으로 두지 마세요**

> "가까운 지하철역 없으면 소비자가 알아야지 거긴 없구나" (사장님)

빈칸이면 손님은 "이 앱이 모르는구나"라고 생각합니다.
**「여긴 역이 없습니다」**라고 적으면 그건 쓸모 있는 정보가 됩니다.

### 3. **남은 라커 수는 절대 적지 마세요**

또타라커 앱 지도는 역을 누르면 **지금 비어 있는 칸 수**까지 보여 줍니다.
탐나지만 베끼면 안 됩니다. 사장님 말씀입니다:

> "이거는 어플이 우리보다 서비스 질이 좋아 / 우리는 가까운 역까지만 안내하는 게 답이야
>  ... 남은 락커를 우리가 관리할 수 없잖아"

5분 뒤면 틀린 숫자가 됩니다. **케이푸드는 이미 값에서 데었습니다** —
메뉴판 6장을 대조하니 6곳 중 5곳이 틀렸습니다. 같은 종류의 사고입니다.

### 4. **값을 적었으면 「바뀔 수 있다 + 확인한 날」을 반드시 같이**

요금표를 실은 이상 이건 짝입니다. 케이푸드가 메뉴 값에 쓰는 잣대와 같습니다.

## 🧹 하나 더 — 사실은 파일 하나에만

K-Street는 같은 표(지점·요금·시간·주소)를 **앱과 검색용 낱장 두 곳**에서 쓰게 됐습니다.
두 군데에 적으면 언젠가 어긋납니다 — 그래서 `src/lib/luggageFacts.ts` 하나를
원본으로 두고 나머지가 가져다 씁니다.

케이푸드도 같은 표를 `seed.js`와 화면 코드 양쪽에 적지 마세요.

## 📋 케이푸드 세션에 붙여넣을 글

아래를 통째로 복사해서 케이푸드 세션에 주세요.

```
K-Street 저장소(pyoseongo-hub/k-street)를 보고 케이푸드에도
「가까운 역 + 짐 보관」을 만들어 줘. 베낄 파일:

  · src/components/LuggageCard.tsx        짐 보관 카드 둘 (역 / 또타러기지)
  · src/components/MapDirections.tsx      카드 안 단추 세 개
  · src/lib/luggageFacts.ts               지점·요금·시간·주소 (사실은 여기 하나에만)
  · scripts/dump-place-coords.ts          흩어진 좌표를 한 목록으로
  · scripts/find-nearest-station.mjs      카카오에 가까운 역 묻기
  · scripts/find-luggage-branches.mjs     또타러기지 6곳 좌표 받기
  · docs/케이푸드에도-가까운역-넣기.md      ← 이 설명서 원본

시작하기 전에 **케이푸드 곳들에 좌표가 몇 %나 있는지부터 숫자로 세 줘.**
50% 아래면 좌표부터 채우는 게 순서다.

만들 것:
 ① 식당 카드에 단추 세 개 — 목적지 보여주기 · 주변 먹거리 · **짐 보관(색을 준다)**
    ⚠️ 회색 글자 한 줄로 넣지 말 것. 단추 둘 밑에 묻혀서 안 읽힌다(K-Street가 겪음)
 ② 짐 보관을 누르면 카드 둘:
    첫째 — 가까운 역 이름·거리 + 카카오맵/네이버 (목적지는 식당이 아니라 **역**)
    둘째 — 또타러기지 6개 지점 단추 + 고른 지점 길찾기 + 공식 요금표 + 예약·안내 링크
 ③ 역이 1.5km 안에 없으면 「1.5km 안에 지하철역이 없습니다」라고 **적을 것**

🚨 두 서비스를 한 카드에 섞지 말 것 — 다른 것이다:
   또타라커  무인 보관함 · 273개 역 · 05~24시 · 칸 크기 cm
   또타러기지 사람이 받아 줌 · 6개 역 · 09~22시 · 가방 크기 인치
   섞으면 손님이 밤 11시에 닫힌 창구 앞에 선다.

🚨 남은 라커 수는 **절대 우리 화면에 적지 말 것** — 실시간 값이라 옮기면 틀린다
   (사장님: "남은 락커를 우리가 관리할 수 없잖아").
🚨 「보관함이 있습니다」라고 단정하지 말 것 (273역 / 약 340역).
🚨 요금을 적었으면 「바뀔 수 있습니다 + 확인한 날」을 반드시 함께 띄울 것.
🚨 카카오 호출 실패와 「역이 없다」를 반드시 갈라서 다룰 것. 섞으면 거짓말이 나간다.
🚨 또타러기지 좌표는 **호선까지 넣어서** 묻고 이름이 정확히 일치하는 것만 받을 것 —
   "서울역"으로만 물으면 「서울역 GTX-A」가 잡힌다(K-Street가 실제로 당함).
⚠️ 김포공항역은 출구가 숫자가 아니라 「I-센터」다. 무조건 "번 출구"를 붙이면
   「I-센터번 출구 방면」이 된다.
⚠️ 서울교통공사 주소는 https 가 아니라 **http** 다. 바꾸면 안 열린다.
```
