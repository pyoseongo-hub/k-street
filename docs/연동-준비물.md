# 🔗 연동 준비물 — 무엇을 받아야 이을 수 있나 (2026-09-08)

> 사장님: "케이푸드도 비슷한 작업 중이고 나중에는 서로 링크 안내받아서…"
> 그리고 — **"밀어주기 안 돼. 연동되는 것과 같은 건데."**

이 문서는 **저쪽에 물어볼 것 5가지**와 **우리가 할 것 3가지**다.
그대로 복사해서 저쪽 작업에 넘기면 된다. 맨 아래에 **빈칸 표**를 뒀다.

---

## 0. 이건 홍보가 아니라 기능이다

| | 무엇 | 결과 |
|---|---|---|
| ❌ 밀어주기 | 순위를 올리려고 모든 페이지 밑에 서로 링크를 깐다 | 검색 벌점 |
| ✅ **연동** | 손님이 **지금 필요한 것**을 이어 준다 | 정상. 좋은 링크다 |

**손님은 시장을 구경하고 산책하면 배가 고프다.** 그때 밥집을 못 주면 앱을 닫는다.
그건 홍보 문제가 아니라 **빠진 기능**이다. 반대쪽도 같다 —
밥집을 보러 온 사람에게 그 동네 축제·시장을 이어 주면 된다.

---

## 1. 방식부터 — **링크만 잇는다. 자료를 주고받지 않는다.**

| | 링크 (하기로 한 것) | API로 자료 받아오기 |
|---|---|---|
| 돈 | **0원** | 서버·트래픽 비용이 는다 |
| 준비 | 주소 규칙 하나 | 키 발급·인증·형식 합의·오류 처리 |
| 한쪽이 죽으면 | 링크만 안 열린다 | **우리 화면이 같이 느려지거나 멈춘다** |
| 자료 정확도 | 저쪽 화면이 늘 최신 | 우리가 복사해 두면 **옛 자료가 남는다** |

📌 **지금은 링크가 맞다.** 고정비를 안 늘린다는 원칙에 맞고, 하루면 붙는다.
자료를 직접 받아 오는 것은 링크가 실제로 눌리는 것을 확인한 뒤에 생각할 일이다.

## 2. 저쪽에서 받아야 할 것 — 5가지

### ① 동네 페이지 주소 **예시 하나** (진짜로 열리는 것)

- **무엇** — 「종로구 밥집 목록」이 열리는 실제 주소 한 줄.
  예: `https://……/area/jongno` · `https://……/?gu=종로구`
- **왜** — 규칙을 **눈으로 확인해야** 한다. 말로 들은 규칙은 어긋날 때가 많다
  (이 저장소에서 여러 번 데였다 — 회색 예시 글씨를 값으로 착각한 일, 검색어를
  고쳤는데 결과가 그대로였던 일). 하나를 열어 보고 나머지 24개를 만든다.
- **확인법** — 폰 주소창에 붙여넣어 **밥집 목록이 나오면 끝.**

### ② 동네를 **무엇으로 부르나** (열쇠)

- **무엇** — 주소 안의 동네 부분이 어떤 값인가:
  `종로구`(한글) · `jongno-gu`(로마자) · `11110`(법정동 코드) · `17`(내부 번호)
- **왜** — 우리 손에 있는 것은 **「종로구」라는 한글 이름**이다. 저쪽이 다른 값을
  쓰면 **표가 한 장 필요**하다. 특히 로마자는 표기가 갈린다 —
  `jongno` / `jongro` / `jong-no`. **이건 추측하면 거의 틀린다.**
- **같이 알려 줄 것** — 구 단위만 되나, **동(법정동)까지 되나?**
  우리는 곳마다 법정동을 갖고 있어서, 동까지 되면 훨씬 정확히 이어 준다.
- **가장 좋은 답** — **법정동 코드**(행정표준코드). 표기 논쟁이 아예 없다.

### ③ 자료가 **실제로 있는 동네** 목록과 곳 수

- **무엇** — 서울 25개 구 중 어디에 몇 곳이 있나. (예: 종로구 412 · 강북구 0)
- **왜** — 🚨 **비어 있는 동네로는 링크를 안 그린다.** 눌렀는데 「결과 없음」이
  나오면 손님은 **두 앱 다** 못 믿게 된다. 우리 앱은 이미 이 규칙으로 돈다 —
  주소가 없는 곳은 공유 단추를 아예 안 그린다(`src/lib/shareLink.ts`).
- **형식** — 표 한 장이면 된다. 정확한 숫자가 아니어도 되고
  **0인 곳이 어디인지**만 확실하면 된다.

### ④ **외국어로 열리나** ← 가장 중요

- **무엇** — 그 페이지가 영어로 열리나? 주소로 언어를 정할 수 있나
  (`?lang=en` 같은)? 되는 언어는 무엇무엇인가?
- **왜** — **우리 손님은 한국어를 못 읽는다.** 12개 언어로 안내해 놓고 마지막에
  한글 화면으로 보내면 그 손님은 거기서 끝난다. **링크를 안 거는 것만도 못하다.**
- **안 되면** — 그래도 방법은 있다:
  · 한국어를 쓰는 손님(ko)에게만 링크를 그린다
  · 또는 「Korean-language page」라고 **미리 알려 주고** 링크한다
  다만 둘 다 임시 방편이고, 영어가 되는 쪽이 비교가 안 되게 낫다.

### ⑤ **주소를 안 바꾼다는 약속**

- **무엇** — 한번 정한 주소 모양을 바꾸지 않는다. 꼭 바꿔야 하면 **옛 주소가
  새 주소로 넘어가게**(리다이렉트) 해 준다.
- **왜** — 우리는 구별 페이지 25장 + 앱 화면에 링크를 박는다. 저쪽이 주소를
  바꾸면 **아무 소리 없이 전부 죽는다.** 죽어도 우리는 모른다 — 손님만 안다.
- **우리도 같은 약속을 한다** — `/seoul/jongno-gu/` 와 곳 주소 307개는 안 바꾼다
  (`src/data/place-slugs.json` 에 id 를 열쇠로 못 박아 뒀다).

### (선택) ⑥ 되돌아오는 링크

저쪽 동네 페이지에서 **「이 동네 축제·시장」**으로 오는 한 줄.
우리 쪽 주소는 이미 준비돼 있다 — `korea-street.com/seoul/<구>/` (25장).

| 구 | 주소 |
|---|---|
| 종로구 | `korea-street.com/seoul/jongno-gu/` |
| 강남구 | `korea-street.com/seoul/gangnam-gu/` |
| … | 로마자 구 이름 + `-gu` (25개 전부 같은 규칙) |

## 3. 우리가 할 것 — 3가지 (위가 오면 반나절)

| | 무엇 | 왜 |
|---|---|---|
| 1 | **표 한 장** — 우리 구·동 → 저쪽 주소 | 코드 여기저기에 주소를 박으면 저쪽이 바꿀 때 어디를 고칠지 아무도 모른다 |
| 2 | **링크 부품** — 표에 있을 때만 그린다 | 없는 주소를 지어내지 않는다(공유 단추와 같은 규칙) |
| 3 | **12개 언어 글자** — "Where to eat in Jongno-gu" | 링크는 **무엇이 나오는지** 말해야 한다. 앱 이름만 적으면 아무도 안 누른다 |

**붙일 자리** — 구별 페이지 25장 · 곳 페이지 307장 · 앱에서 구를 고른 화면.
⚠️ 한꺼번에 셋 다 붙이지 않는다. **구별 페이지 한 곳에 먼저** 붙여 보고,
눌리는지 보고 늘린다.

| | 저쪽 답 | 우리가 정한 것 |

| ④ 언어 | `?hl=en` · 화면 12개 언어 | 묶음 페이지는 영어라 `hl=en` 고정. 앱은 손님 언어를 넘긴다(2단계) |

### 🚨 딱 한 글자 — `zh-TW` vs `zhTW`

12개 언어 중 **대만 중국어만 표기가 다르다.** 안 맞추면 **대만 손님만** 엉뚱한
화면을 받는다. 눈으로는 안 보이고 손님이 적어 한참 뒤에나 발견된다.
→ `partnerLang()` 이 이 한 글자를 갈아 끼운다(`src/lib/partnerLinks.ts`).

### 우리 쪽 상태

- `src/lib/partnerLinks.ts` — 표 한 장. 주소는 **여기서만** 만든다
- 구별 페이지 25장에 「Where to eat in Jongno-gu →」 한 줄이 붙게 해 뒀다

  **인터넷에 올라간 것을 눈으로 확인한 뒤** 켠다. 확인 전에 켜면
  눌렀을 때 빈 화면이 뜨고, 그러면 손님은 **두 앱 다** 못 믿는다
- 켜 놓고 한 번 만들어 봤다 — 25장 전부에 제대로 붙는 것을 확인하고 되돌렸다

### 남은 확인 두 가지

1. **주소 끝 빗금** — `/seoul/jongno-gu` 와 `/seoul/jongno-gu/` **둘 다 열리게** 해 달라.
   한쪽만 되면 누군가 빗금을 붙이는 날 조용히 깨진다
2. **인터넷에서 열리나** — 저쪽 확인은 「로컬로 직접 열어」 본 것이다.
   진짜 주소(`kfood-t493.onrender.com/seoul/jongno-gu`)가 **폰에서** 열려야 켠다

## 🔌 켰다 (2026-09-08) — 확인 방법과 결과

작업 세션은 바깥 인터넷이 막혀 있다. 그래서 **러너에서** 실제 주소를 두드렸다
(`scripts/check-live.mjs` ⑥⑦ · Actions → Check live site).

### ⑥ 주소 끝 빗금 — **우리 쪽도 이미 둘 다 열린다**

```
✅ 200  /seoul/jongno-gu          ✅ 200  /seoul/jongno-gu/
✅ 200  /seoul                    ✅ 200  /seoul/
✅ 200  /place/gwangjang-market   ✅ 200  /place/gwangjang-market/
```

폴더 안 index.html 이라 빗금 없는 쪽은 GitHub Pages 가 넘겨 준다.
**200 만 보지 않는다** — 첫 화면(앱)이 대신 떠도 200 이다. 그 페이지에만 있는
`canonical` 이 있는지까지 봐서 「그 페이지가 맞는지」를 확인한다.

### ⑦ 밥집 쪽 — 인터넷에서 열린다

```
200  /seoul/jongno-gu    8,880자 · 한글 1,389자
     제목: Best Korean Restaurants in Jongno-gu, Seoul | Kfood
200  /seoul/jongno-gu/   위와 같다 (빗금 있어도 같은 페이지)
200  /seoul/jung-gu      8,867자 — 구마다 내용이 다르다
```

**제목이 영어**이고 **한글이 1,389자 남아 있다** — 딱 맞다. 가게 이름은 한국어라야
손님이 가게에서 그대로 말할 수 있다(우리 앱도 같은 규칙이다).

### ⚠️ 아직 확인 못 한 것 — `hl` 이 정말 화면을 바꾸나

`?hl=ja` 를 붙여도 **서버가 주는 HTML 이 똑같았다**(제목·글자 수 모두).
언어 갈아 끼우기가 **브라우저 안에서** 일어난다는 뜻이다 — 기계로는 확인이 안 된다.

- 지금 켠 것(구별 페이지 25장)은 **`hl=en` 고정**이라 문제가 없다.
  안 바뀌어도 영어 화면이고, 원래 영어를 보내려던 것이다.
- 🚩 **2단계(앱 안에 붙일 때) 전에는 사람이 봐야 한다.** 그때는 손님 언어를
  그대로 넘긴다 — 일본어 손님에게 `hl=ja` 를 보냈는데 안 바뀌면 그 손님은 끝이다.
  폰에서 `?hl=ja` 를 한 번 열어 보는 것으로 끝난다.

## 🔭 2단계 후보 — 저쪽 「동네」 페이지 (2026-09-08 확인)

저쪽이 구 25개 말고 **관광객이 아는 이름** 12곳에도 페이지를 만들었다.
러너에서 두드려 확인한 것:

| 주소 | 제목 |
|---|---|
| `/seoul/hongdae` | Where to Eat in Hongdae, Seoul |
| `/seoul/gwangjang-market` | Best Street Food Stalls at Gwangjang Market, Seoul |
| `/seoul/bukchon` | Where to Eat Near Bukchon Hanok Village & Insadong |
| `/seoul/euljiro` | Best Restaurants & Bars in Euljiro (Hipjiro) |
| `/seoul/gwangjang` | ❌ 404 — 내가 이름을 잘못 짚은 것이다 |

**규칙: 관광객이 부르는 이름을 로마자로.** 구 페이지(`jongno-gu`)와 같은 자리에 있다.

### 🥇 가장 값어치 있는 한 줄 — 광장시장

우리 곳 페이지에 **광장시장**이 있고(`/place/gwangjang-market/`),
저쪽에도 **같은 이름**이 있다(`/seoul/gwangjang-market`).

광장시장을 보러 온 사람은 **먹으러 가는 것**이다 — 시장 자체가 먹거리다.
곳 페이지 307장 중 이만큼 맞아떨어지는 자리는 없다.

### ⚠️ 나머지는 판단이 필요하다

「이 곳이 홍대인가」는 자료로 안 풀린다. 우리는 법정동(서교동·동교동…)을 갖고 있고
저쪽 「홍대」는 여러 동을 묶은 이름이다. **묶는 규칙을 사람이 정해야 한다** —
잘못 묶으면 성수동 가게를 홍대라고 소개하는 꼴이 된다.

📌 그래서 순서: **광장시장 한 줄 → 되는 것 보고 → 동네 6곳(서울) 묶기.**
   서면·해운대·전주한옥마을은 서울 밖이라 우리와 상관없다.
