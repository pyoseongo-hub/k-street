**「차 없는 잠수교 뚜벅뚜벅 축제」가 2026-10-25(일)로 끝난다.**
10/26(월) 0시부터 잠수교가 보행전용교 공사에 들어가 차량이 전면 통제된다.

사장님 판단 (2026-10-18):

> *"공사를 하면 당연히 사람이 거기 안 가서 그런 것까지 알 필요 있나.

>  이런 게 더 먹히지"*

| 2026-10-26 (월) 0시 | **차량 통행 전면 통제** 시작 · 공사 착공 |
| 공사 중 | **보행자·자전거는 계속 통행 가능** (작업공간과 통행공간을 분리) |
| 2027년 5~8월 중 | 포장공사 — **보행자·자전거도 전면 통제**, 우회로 안내 |

(한강유역환경청 협의 완료). 교통영향 분석 결과 반포대교 우회로도 서비스 수준은 유지.

### 🚨 적지 말아야 할 것 두 가지

1. **"다시는 없다"고 쓰지 않는다.** 서울시가 말한 것은 **"올해 마지막"**이다.
   같은 글에 완공 뒤 *"계절별 야외 축제와 거리 공연, 플리마켓"*을 하겠다고 적혀 있다.
   → 안전한 표현은 **"차가 다니던 잠수교에서 열리는 마지막 축제"**다. 이건 100% 사실이다.
2. **버스 날짜를 적지 않는다.** 서울시 글에 적힌 것은 이 한 줄이 끝이다 —
   *"잠수교를 경유하던 740번·405번 시내버스는 상·하행 모두 반포대교로 우회 운행한다"*.
   **날짜가 없다.** 「반포한강공원·세빛섬」 정류장 양방향 2개소 폐쇄는 언론 세 곳이
   같은 보도자료를 인용해 전했지만 **거기에도 날짜가 없다.** 상식으로는 10/26이지만
   **적혀 있지 않은 것은 적지 않는다.**
   · 사장님 지시로 **버스 안내는 넣지 않기로 했다.** 다만 폐쇄되는 정류장 이름이
     「반포한강공원·세빛섬」이고 **공원과 세빛섬은 계속 연다** — 영향받는 쪽은
     다리 손님이 아니라 **공원 손님**이다. TOPIS 공지에 날짜가 뜨면 그때 함께 넣는다.

### 날짜는 이미 맞게 들어가 있다 — 고치지 말 것

`src/data/festival-dates-manual.json`의 `ks_58`에 `end: "2026-10-25"`가 이미 있고,
10/25가 일요일인 것까지 기사와 맞는다. **건드릴 필요 없다.**

`src/data/seed.ts:572`의 `startMonth: 9, endMonth: 10` · `"9~10월 매주 일요일"`은
**2027년에는 틀린다.** 다만 2027년에 같은 축제가 열리는지는 **어디에도 안 적혀 있다** —
그래서 지금 손대면 추측이 된다. **2027년 공지가 나올 때 본다.**

## 🖼️ 사장님이 그려 주시기로 한 배너 3장

지금 배너 덮는 범위는 **564/607곳(93%)**이다 (`npm run banner-cover`).
남은 세 갈래는 「저녁 빛」 컨셉으로 가기로 했다.

| 갈래 | 몇 곳 | 상태 |
|---|---:|---|
| `festival-night` | 17 | 프롬프트 드렸다 (사장님: *"야시장은 어둡게등 디테일"* → 밤으로 다시 씀) |
| `street-market` | 17 | 프롬프트 드렸다 (해 질 녘 아케이드) |
| `walk-path` | 9 | 프롬프트 드렸다 (황금빛 시간) |

넣는 법은 **한 줄**이다. 규격(1200×800 · 180KB 이하)을 **넣을 때** 맞춘다 —
사장님 지시: *"이미지 크기 조절해서 넣어 그전처럼 그냥 넣고 나중에 조절하지 말고"*.

```
python3 scripts/add-banner.py <받은파일> festival-night
```

넣은 뒤 `src/lib/placeBanner.ts`의 `있는배너`에 그 이름을 **추가해야** 화면에 나온다.
검사는 `npm run banner-size`(규격)와 `npm run ai-banner`(og:image에 새지 않는지)다.
