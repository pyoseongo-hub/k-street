### 🚨 나눴다고 끝이 아니었다 — 서비스워커가 열한 개를 **미리** 다 받고 있었다
`globPatterns` 의 `assets/**` 에 걸려, 설치할 때 통째로 내려받았다. 그러면 나눈 뜻이
없어진다(받는 양이 그대로다). 그래서 —
· 말 조각 파일 이름 앞에 **`i18n-`** 을 붙이고(`vite.config.ts` 의 `chunkFileNames`),
· `globIgnores` 로 미리 받는 목록에서 빼고,
· `runtimeCaching` 으로 **손님이 실제로 받은 것만** 저장한다(한 번 받으면 오프라인에서도 보인다).

### 🐞 여기서 **영어 손님만** 한국어 이름을 보는 사고가 났다
브라우저로 네 언어를 다 돌려 보다 잡았다. 순서가 이랬다 —
① 화면이 한국어로 먼저 뜬다 → 예비용 영어를 받기 **시작**하면서 「받았음」을 미리 찍는다
② 말이 'en' 으로 정해져 다시 부른다 → 표시가 있으니 **그냥 지나간다**
③ 「준비됐다」며 화면을 그린다 — **①은 아직 도착 전**이라 표가 비어 있다
일본어는 ②에서 일본어를 진짜로 기다리니 멀쩡했다. **영어만** 걸리는 자리였다.
→ 표시(`Set`)가 아니라 **받는 중인 약속(`Map<string, Promise>`)** 을 들고 있게 고쳤다.
⏳ 교훈: **「시작했다」와 「도착했다」를 같은 표시로 쓰면 안 된다.**

### 🧾 두 벌로 두지 않았다
합친 파일을 남기고 나눈 것을 따로 만들면 언젠가 어긋난다. **나눈 것만 저장**하고,
합친 모양이 필요한 쪽(스크립트·감사·파이썬)은 `scripts/lib/place-translations.mjs`
한 군데서 읽는다. 곳 페이지를 만들 때는 11개를 다 넣는다(12개 언어를 한 번에 만든다).

✅ **곳 페이지 9,880장 중 9,879장이 한 글자도 안 달라졌다** (다른 하나는 파일 이름
해시가 바뀐 `index.html`). 고치기 전에 해시를 통째로 떠 두고 맞춰 봤다.
