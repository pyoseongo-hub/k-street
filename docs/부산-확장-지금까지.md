## 🔜 남은 것

### 1. 이름을 쪼개서 처리하기 ← **다음에 할 일. 사장님이 ② 를 권한 흐름**
사장님: *"지명은 번역 말고 고유의 고유명사로 불리는 거지"* — 맞는 말이다.

지금은 이름 **전체**를 구글에 던지고, 사고가 나면 하나씩 고치고 있다.
그래서 「잠수교 → ウェットスーツ(잠수복)」·「김장 → 참치」가 나왔다.

→ **고유명사는 손대지 않고, 뒤에 붙는 보통명사만** 그 나라 말로 바꾼다:
```
해운대해수욕장  →  [해운대]    + [해수욕장]
                   그대로 둔다    Beach / 海水浴場 / ชายหาด
```
보통명사는 종류가 뻔하다(시장·공원·산·해수욕장·전망대·거리·골목·절).
**사고가 날 자리를 없애는** 방식이다.

### 2. 곳 페이지 주소가 `seoul/` 로 박혀 있다
`scripts/build-place-pages.ts` 6군데 + 12개 언어 문구(`S.seoul`·`S.allOfSeoul`).
🚨 6,073개 주소를 건드리는 일이다. **고치기 전 결과를 통째로 해시로 떠 두고**
고친 뒤와 맞춰 볼 것 — 오늘 CSS 주석 뗄 때 그렇게 해서 6,075장이 한 글자도
안 달라진 걸 확인했다.

### 3. 🪪 관광공사 다국어 서비스 — **사장님이 신청해야 한다**
`JpnService2`·`ChsService2`·`EngService2` … 는 **있다.** 그런데 우리 인증키가
그쪽에 등록돼 있지 않다:
```
KorService2  ✅ 됩니다 (지금 쓰는 것)
JpnService2  ❌ HTTP 403  SERVICE_KEY_IS_NOT_REGISTERED
```
공공데이터포털에서 언어별로 **활용 신청**을 한 번 하면 된다(무료).
⚠️ **그 안의 이름을 아직 한 건도 못 봤다** — 서비스가 있다는 것까지만 확인했다.
열어 보고 별로면 안 쓰면 된다. 확인용: Actions → **Probe tour langs**

### 4. 부산 축제는 관광공사 자료가 약하다
14곳뿐이고 **부산국제영화제·불꽃축제·바다축제가 없다.** 「크리스마스 빌리지
2025」 같은 작년 것이 섞여 있다. 서울처럼 **부산시·구청 자료**를 따로 받아야 한다.

## 🧰 자주 쓰는 명령

```bash
# 새 도시 조사 (Actions → Survey city · save 를 켜면 자료가 저장소에 들어온다)
node scripts/build-city-places.mjs --city busan --area 6          # 맛보기
node scripts/build-city-places.mjs --city busan --area 6 --apply  # 저장

node scripts/check-tour-categories.mjs   # 분류표가 자료에 맞나
node scripts/check-city-places.mjs       # id 겹침·동네 이름·http 사진·튄 좌표
node scripts/check-hex-maps.mjs          # 벌집 지도가 명부와 맞나
node scripts/check-cjk-names.mjs         # 한자권에 확실히 틀린 말이 있나

node scripts/translate-places.mjs --overrides-only   # 이름만 고칠 때(구글 열쇠 불필요)
```

🪪 **이름이 틀렸을 때 고치는 곳** — `src/data/name-overrides.json`.
한자를 확인 못 하면 `null` 을 적어 **지운다**. 앱이 영어로 대신 보여 준다.
**틀린 이름보다 영어가 낫다.**
