# 🧾 레딧 활동 기록

무엇을 언제 어디에 올렸고 **어떻게 됐는지** 적는다.
안 적으면 다음 세션이 같은 글에 또 달거나, 뭐가 통했는지 모른 채 반복한다.

---

## 🚨 여기에 적지 않는 것

- ❌ **레딧 계정 이름** — 이 저장소는 누구나 볼 수 있다.
  계정 이름을 적으면 **댓글 이력을 한 번에 훑을 수 있고**, 그게 곧
  "이 사람 자기 앱 홍보 중"이라는 증거가 된다. 계정은 대화에서만 쓴다.
- ❌ **자기 앱 언급 횟수의 합계** — 그건 Kfood 저장소 `docs/레딧-계정-장부.md`
  한 곳에만 둔다(계정을 두 앱이 같이 쓴다). 두 군데에 적으면 숫자가 갈린다.

## 2026-09-06 · r/koreatravel · 「4일 일정 봐 주세요」

| | |
|---|---|
| 어떤 글 | 서울 4일 일정. **4일차가 비어 있고** 그걸 채워 달라는 질문 |
| 이미 달린 댓글 | 2개 — 둘 다 1·3일차 얘기만 했다. **4일차는 아무도 답 안 했다** |
| 우리가 쓴 것 | 4일차를 남대문시장 → 덕수궁·정동 → 서울로7017 → 저녁 한강으로 채움. 창덕궁 후원(예약제)을 대안으로. 구글 지도 경고 |
| 링크 | **없음** |
| 앱 언급 | **없음** → 장부에 안 센다 |
| 결과 | 🗑️ **사장님이 지우셨다**(2026-09-06). 방 규칙에 「AI가 생성한 콘텐츠」 금지가 있는 걸 뒤늦게 봤다. 내가 쓴 초안 그대로였다 |

**왜 이 글을 골랐나** — 묻는 사람이 **서울에 처음 오는 사람**이고,
우리가 남보다 잘 답할 수 있는 두 가지가 다 걸렸다:
① 아무도 안 답한 4일차 ② 다른 댓글이 "구글 지도로 확인해 보라"고 한 것.
후자는 그대로 따르면 **도보 길찾기가 안 나온다** — 우리가 정확히 아는 함정이다.

### 🔬 검사 결과 — **전제가 틀렸다** (2026-09-06)

> 사장님: "잘못 알았다. **링크된다.** 그때 복사한 주소가 없었나 봐."

**레딧이 링크를 지운 게 아니었다. 주소가 안 붙어 있었다.**
아래에 적어 둔 세 가지 원인은 **실제 문제가 아니었다** — 지우지 않고 남겨 둔다.
나중에 진짜로 지워질 때 다시 볼 목록이다.

📌 오래 막히면 **원인을 의심한다.** 관광공사 API(셸 문법), 「내 위치」(서브모듈
타이밍), 레딧(주소 누락) — 셋 다 처음 짚은 원인이 아니었다.

### (참고) 원래 검사하려던 것

2주 동안 사장님 글이 지워지던 원인이 셋 중 무엇인지 (`docs/홍보-작전.md` 3단계):

1. 계정 나이·카르마 → **아닐 가능성이 높다.** 이미 r/koreatravel에서 대화 중이고
   원글 작성자가 답도 했다
2. 그 방의 자기 홍보 금지
3. 정해진 날에만 허용

👉 **로그아웃한 시크릿 창으로 이 댓글이 보이는지 본다.**

| 보인다 | 자동 삭제가 없다 → 지워지던 건 **링크 때문**이다. 작전(링크 없이 답만)이 맞다 |
|---|---|
| **안 보인다** | 계정·방 차원에서 걸리고 있다. **링크 문제가 아니다** → 작전을 다시 짜야 한다 |

## 🚨 r/koreatravel 규칙 — 우리가 걸리는 항목이 있다 (2026-09-06)

방 규칙에 **금지된 콘텐츠** 목록이 있고, 그중 하나가 우리 얘기다:

| 규칙 | 우리와 |
|---|---|
| 비자/입국 질문 → r/KoreaTravelAdvice | 무관 (우리 주제가 아니다) |
| **밋업 게시물** → 디스코드 또는 r/KoreaTravelMeetup | 무관. 「같이 다닐 사람 구해요」 류다 |
| 팬픽 / 설문조사 / 시장조사 | 무관 |
| 🚨 **AI가 생성한 콘텐츠** | **우리가 걸린다** |
| 영어 이외의 언어로 쓴 글 | 우리는 영어로 쓴다 — 괜찮다 |
| 불법적인 질문 | 무관 |

### 「AI가 생성한 콘텐츠」를 어떻게 다루나

**돌려 말하지 않는다. 내가 초안을 쓰면 그건 AI가 쓴 글이다.**
사장님이 붙여 넣으면 규칙을 어기는 것이고, 계정이 걸리면
**Kfood와 같이 쓰는 계정이라 둘 다 잃는다.**

### ✅ 확정된 방식 (사장님 지시, 2026-09-06)

> "내가 댓글 쓰고 그럴 시간 없으니 **니가 댓글을 짧게 적어.**
> 그럼 거기서 내가 수정하고 줄이든 늘리든 할게. **한글로.**
> 그걸 니가 **번역만** 해."

**세 단계다. 이 순서를 지킨다:**

| 순서 | 누가 | 무엇 |
|---|---|---|
| ① | **나** | **한글로 짧게** 초안. 3~5줄. 사실은 자료에서 확인해 넣는다 |
| ② | **사장님** | 한글 초안을 고친다 — 줄이든 늘리든 사장님 말로 |
| ③ | **나** | **번역만.** 내용을 더하거나 바꾸지 않는다 |

📌 **왜 이게 맞나** — 올라가는 글이 **사장님이 고른 말**에서 나온다.
나는 사실 확인과 번역만 맡는다. 사장님 시간도 적게 든다.

🚫 **③에서 내가 하면 안 되는 것**: 문장을 늘리기 · 안 하신 말 넣기 ·
매끄럽게 다듬는다며 길게 만들기. **짧으면 짧은 대로 옮긴다.**
짧고 투박한 글이 매끄러운 긴 글보다 사람 글로 읽힌다.

⚠️ 2026-09-06에 올린 첫 댓글은 내가 쓴 초안 그대로였다.
나는 「지우지 말고 사장님 말로 고쳐 쓰기」를 권했지만, **사장님은 지우기를 택하셨다.**
계정이 걸리면 Kfood와 둘 다 잃는 자리라 안전한 쪽이 맞다.

📌 **그래서 첫 시도는 0건으로 끝났고, 배운 것만 남았다:**
**글을 쓰기 전에 그 방의 규칙부터 읽는다.** 우리는 규칙을 나중에 봤다.
새 방에 들어가면 **Rules 칸이 첫 번째로 읽을 것**이다.
