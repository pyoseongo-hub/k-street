# 🧾 레딧 활동 기록

무엇을 언제 어디에 올렸고 **어떻게 됐는지** 적는다.
안 적으면 다음 세션이 같은 글에 또 달거나, 뭐가 통했는지 모른 채 반복한다.

---

## 🚨 여기에 적지 않는 것

- ❌ **레딧 계정 이름** — 이 저장소는 누구나 볼 수 있다.
  계정 이름을 적으면 **댓글 이력을 한 번에 훑을 수 있고**, 그게 곧
  "이 사람 자기 앱 홍보 중"이라는 증거가 된다. 계정은 대화에서만 쓴다.
- ❌ **자기 앱 언급 횟수의 합계** — 그건 Kfood 저장소 `docs/레딧-계정-장부.md`
  한 곳에만 둔다(계정을 두 앱이 같이 쓴다). 두 군데에 적으면 숫자가 갈린다.

## 2026-09-06 · r/koreatravel · 「4일 일정 봐 주세요」

| | |
|---|---|
| 어떤 글 | 서울 4일 일정. **4일차가 비어 있고** 그걸 채워 달라는 질문 |
| 이미 달린 댓글 | 2개 — 둘 다 1·3일차 얘기만 했다. **4일차는 아무도 답 안 했다** |
| 우리가 쓴 것 | 4일차를 남대문시장 → 덕수궁·정동 → 서울로7017 → 저녁 한강으로 채움. 창덕궁 후원(예약제)을 대안으로. 구글 지도 경고 |
| 링크 | **없음** |
| 앱 언급 | **없음** → 장부에 안 센다 |
| 결과 | ✅ 올라감. **링크도 정상 작동**한다는 것이 같은 날 확인됐다 |

**왜 이 글을 골랐나** — 묻는 사람이 **서울에 처음 오는 사람**이고,
우리가 남보다 잘 답할 수 있는 두 가지가 다 걸렸다:
① 아무도 안 답한 4일차 ② 다른 댓글이 "구글 지도로 확인해 보라"고 한 것.
후자는 그대로 따르면 **도보 길찾기가 안 나온다** — 우리가 정확히 아는 함정이다.

### 🔬 검사 결과 — **전제가 틀렸다** (2026-09-06)

> 사장님: "잘못 알았다. **링크된다.** 그때 복사한 주소가 없었나 봐."

**레딧이 링크를 지운 게 아니었다. 주소가 안 붙어 있었다.**
아래에 적어 둔 세 가지 원인은 **실제 문제가 아니었다** — 지우지 않고 남겨 둔다.
나중에 진짜로 지워질 때 다시 볼 목록이다.

📌 오래 막히면 **원인을 의심한다.** 관광공사 API(셸 문법), 「내 위치」(서브모듈
타이밍), 레딧(주소 누락) — 셋 다 처음 짚은 원인이 아니었다.

### (참고) 원래 검사하려던 것

2주 동안 사장님 글이 지워지던 원인이 셋 중 무엇인지 (`docs/홍보-작전.md` 3단계):

1. 계정 나이·카르마 → **아닐 가능성이 높다.** 이미 r/koreatravel에서 대화 중이고
   원글 작성자가 답도 했다
2. 그 방의 자기 홍보 금지
3. 정해진 날에만 허용

👉 **로그아웃한 시크릿 창으로 이 댓글이 보이는지 본다.**

| 보인다 | 자동 삭제가 없다 → 지워지던 건 **링크 때문**이다. 작전(링크 없이 답만)이 맞다 |
|---|---|
| **안 보인다** | 계정·방 차원에서 걸리고 있다. **링크 문제가 아니다** → 작전을 다시 짜야 한다 |
