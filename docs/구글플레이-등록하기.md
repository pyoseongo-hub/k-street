# 📱 구글 플레이스토어에 올리기 — 준비 다 됐습니다

**2026-09-10에 만들었습니다.** 사장님 말씀에서 시작했습니다:

> "우리 앱도 레딧 갔는데 링크 주면 누가 누르겠어? / 어플화하는 게 맞는 거 같은데"

맞는 말씀입니다. `korea-street.com` 링크는 **누가 만들었는지 알 수 없는 주소**로 보이고,
플레이스토어 페이지는 **심사를 거친 것**으로 보입니다. 같은 앱인데 신뢰가 다릅니다.

사장님 결정(2026-09-10): **「일단 준비만」** — 그래서 돈은 아직 안 냈고,
필요한 것만 다 만들어 뒀습니다.

---

## 🎯 먼저 알아 두실 것 — **앱은 이미 만들어져 있습니다**

K-Street는 **PWA**입니다. 새로 만들 게 없습니다:

| | 상태 |
|---|---|
| 앱 아이콘 (192·512·마스커블) | ✅ 있음 |
| 주소창 없이 열리는 설정 (`standalone`) | ✅ 있음 |
| 오프라인에서도 열리게 하는 서비스워커 | ✅ 있음 |
| 아이폰용 태그 | ✅ 있음 |
| 「홈 화면에 추가」 안내 화면 | ✅ 있음 |
| 폰 화면 사진 3장 | ✅ 있음 (오늘 새로 찍음) |
| 개인정보처리방침 | ✅ 있음 (`/privacy/`) |

지금 **없는 것은 「스토어 페이지」 하나**뿐입니다.

## 📋 순서 — 여덟 걸음

> 🚨 **한 번에 하나씩 하세요.** 막히면 멈추고 저에게 물어보세요.
> 혼자 여러 번 다시 하는 게 가장 오래 걸립니다.

### ① 구글 플레이 콘솔 계정 만들기

<https://play.google.com/console> 에서 개발자 등록을 합니다.

- **개인**이 아니라 **개인 개발자**로 하시면 됩니다(사업자 등록 없이 가능)
- 신분 확인에 **며칠** 걸릴 수 있습니다. 이게 제일 오래 걸리는 부분입니다
- 여기서 등록비를 냅니다

### ② 앱 이름과 소개글 — **이미 써 뒀습니다**

`docs/스토어-소개글.md` 에 있습니다. 복사해서 붙이시면 됩니다.

### ③ 화면 사진 — **이미 찍어 뒀습니다**

`public/screenshots/` 에 세 장 있습니다 (1080×1920).

다시 찍으려면:

```
npm run build
npm run place-pages
npx http-server dist -p 8131 -s
node scripts/make-screenshots.mjs 8131
```

⚠️ **사진은 반드시 낡습니다.** 화면을 크게 바꾼 뒤에는 다시 찍으세요.

### ④ 개인정보처리방침 주소 — **이미 있습니다**

구글이 **반드시** 요구합니다. 이 주소를 넣으시면 됩니다:

```
https://korea-street.com/privacy/
```

이 앱은 **아무것도 수집하지 않아서** 쓸 내용이 거의 없었습니다 —
계정 없음, 분석 도구 없음, 광고 없음, 위치는 폰 밖으로 안 나감.
이게 스토어에서는 오히려 **강점**입니다.

### ⑤ 「데이터 보안」 양식

구글이 묻는 표입니다. **전부 「아니요」**로 답하시면 됩니다:

| 묻는 것 | 답 |
|---|---|
| 데이터를 수집합니까? | **아니요** |
| 데이터를 제3자와 공유합니까? | **아니요** |
| 계정이 필요합니까? | **아니요** |

⚠️ 위치는 「수집」이 아닙니다 — **폰 안에서만 쓰고 전송하지 않기 때문**입니다.
구글 양식에도 그렇게 구분하는 칸이 있습니다. 헷갈리면 저에게 물어보세요.

### ⑥ TWA 만들기 (웹을 안드로이드 앱으로 감싸기)

**Bubblewrap**이라는 구글 공식 도구를 씁니다.

```
npx @bubblewrap/cli init --manifest https://korea-street.com/manifest.webmanifest
npx @bubblewrap/cli build
```

- 이때 **서명 열쇠(keystore)**를 만듭니다 — 🚨 **이 파일을 잃어버리면 앱을 영영 갱신 못 합니다.** 반드시 따로 보관하세요
- 결과물 `app-release-bundle.aab` 를 플레이 콘솔에 올립니다

⚠️ 이 걸음은 **컴퓨터에 자바(JDK)와 안드로이드 SDK가 필요**합니다.
Bubblewrap이 알아서 받아 주긴 하는데, 시간이 걸립니다.
막히면 그 화면을 그대로 찍어서 보내 주세요.

### ⑦ 주소 확인 파일 올리기 (assetlinks.json)

TWA가 **주소창 없이** 열리려면, `korea-street.com` 이 이 앱의 것임을 증명해야 합니다.
안 하면 앱 안에 크롬 주소창이 그대로 보여서 **앱 같지 않습니다.**

Bubblewrap이 ⑥에서 `assetlinks.json` 파일을 만들어 줍니다. 그걸 여기에 두면 됩니다:

```
public/.well-known/assetlinks.json
```

그러면 배포 후 `https://korea-street.com/.well-known/assetlinks.json` 로 열립니다.

⚠️ **이 파일은 ⑥에서 만든 서명 열쇠의 지문(SHA-256)이 들어갑니다.**
그래서 지금 미리 만들어 둘 수가 없습니다 — 열쇠가 아직 없으니까요.
빈 파일을 만들어 두면 오히려 확인이 실패합니다.

### ⑧ 심사 넣기

처음 올리는 앱은 심사가 **며칠에서 몇 주**까지 걸립니다.
반려되면 사유가 오니 그걸 보내 주세요.

## 🧯 자주 막히는 자리

| 증상 | 진짜 원인 |
|---|---|
| 앱을 열었는데 **주소창이 보인다** | ⑦ assetlinks.json 이 없거나 지문이 안 맞음 |
| 「개인정보처리방침 주소가 유효하지 않다」 | 배포가 안 끝났거나, 주소 끝 `/` 를 빠뜨림 |
| Bubblewrap 이 자바를 못 찾는다 | JDK 를 따로 깔아야 함 — 화면을 보내 주세요 |
| 심사에서 「기능이 부족하다」 | 구글은 드묾(애플에서 흔함). 사유를 보내 주세요 |

## ⚠️ 그런데 — **앱만으로 레딧이 풀리지는 않습니다**

솔직하게 말씀드립니다.

**스토어 링크도 레딧에서는 똑같이 광고로 걸립니다.** 자동 필터가 도메인을 가리지 않습니다.
게시판에 따라서는 스토어 링크를 **더 심하게** 봅니다.

레딧에서 실제로 통하는 것은 이것입니다:

1. **묻는 사람의 질문에 댓글 안에서 답을 다 해 준다** — 링크 없이
2. 그러면 누군가 "그거 어디서 봤어요?"라고 묻는다
3. **그때** 알려 준다

앱은 **「그때 알려 줄 것」을 좋게 만드는 일**이지, 링크를 눌리게 만드는 일이 아닙니다.
둘 다 필요하지만 순서가 있습니다.

🪪 그리고 레딧에 올리기 전에는 **반드시** 케이푸드 저장소의
`docs/레딧-계정-장부.md` 를 먼저 보세요. 계정 하나를 두 앱이 같이 쓰기 때문에
**합쳐서 한 달에 2건**이 한도입니다. 장부를 안 보면 양쪽이 각자 올려서 계정을 잃습니다.
