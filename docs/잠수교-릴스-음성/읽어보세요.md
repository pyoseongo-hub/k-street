# 🎙️ 잠수교 릴스 나레이션

`scripts/make-narration.py` 가 GitHub Actions 에서 만든 것입니다.
**작업 환경에서는 못 만듭니다** — 프록시가 웹소켓을 막습니다.

| 파일 | 목소리 | 무엇이 다른가 |
|---|---|---|
| `ava-그대로.m4a` | en-US-AvaMultilingualNeural | 자막을 그대로 읽는다 (문장은 안 고침) |
| `ava-말하듯.m4a` | en-US-AvaMultilingualNeural | 말하듯 이어 준다 (자막은 그대로, 읽는 말만 고침) |

**목소리는 둘 다 같습니다.** 다른 것은 *읽는 말*뿐입니다 —
한 번에 두 가지를 바꾸면 무엇 때문에 나아졌는지 알 수 없기 때문입니다.

읽는 말은 `scripts/make-narration.py` 의 `SPEECH`(그대로)와
`SPOKEN`(말하듯)에 있습니다. **화면 자막은 둘 다 똑같습니다** —
사장님이 쓰신 것 그대로입니다.

⚠️ 영상에 얹는 것은 `make-reel.py --voice` 가 합니다.
