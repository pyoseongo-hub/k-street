# 🏨 게스트하우스에 두고 올 A4 한 장

**2026-09-11.** 사장님 SEO 계획서 7·8번("게스트하우스용 무료 서울 지도", "외부 협업 대상")에서 나왔다.
첫 장은 `docs/전단/종로구.html` — 브라우저로 열고 `Ctrl+P` 하면 A4 PDF가 된다.

---

## 왜 종이인가 — 이게 초심에 가장 잘 맞는다

이 앱의 문제는 만들 것이 없는 게 아니라 **아는 사람이 없는 것**이다.
그런데 광고는 초심 3번("적은 비용으로 오래")과 부딪히고, 초심 2번은 아예
**"다운로드 수를 목표로 삼지 않는다"**고 못 박았다.

종이는 그 사이를 지나간다:

- **비용이 0에 가깝다.** 뽑는 건 게스트하우스다. 우리는 PDF만 준다.
- **손님이 이미 거기 있다.** 서울에 막 도착해 "내일 뭐 하지"를 정하는 그 순간·그 자리다.
- **조건이 없다.** 수수료도, 제휴 코드도, 노출 대가도 없다 —
  초심 1번("식당에게 돈을 받고 노출을 올려주지 않는다")과 같은 선 위에 있다.

하실 말은 한 줄이다: **"외국인 손님용 무료 동네 안내입니다. 가입도 광고도 없습니다."**

---

## 이 종이가 다른 전단과 다른 점 세 가지

### ① 한국어 이름을 크게 박는다

손님이 못 읽어도 **손가락으로 짚으면** 된다. 맨 아래에 통째로 넣어 뒀다:

```
기사님, 광장시장으로 가 주세요.
```

앱이 `DriverCard` 로 하는 일을 종이로 옮긴 것이다. **이게 K-Street의 진짜 무기**이고,
다른 여행 전단이 절대 안 하는 일이다(영어 이름만 적어 놓으면 택시에서 못 쓴다).

### ② 호선을 색으로만 알려 주지 않는다

①③④⑤⑥ **숫자를 같이 찍는다.** 게스트하우스 프린터는 대개 흑백이다 —
색에만 기대면 인쇄하는 순간 정보가 통째로 사라진다.
(색은 서울 지하철 실제 호선 색을 쓴다. 손님이 역 표지판과 눈으로 맞춰 볼 수 있게.)

### ③ QR 하나로 12개 언어

종이는 한 장인데 손님 언어는 열둘이다. QR은 그 구의 묶음 페이지를 가리킨다.

🚨 **QR은 만들고 나서 반드시 읽어서 확인한다.** 종이에 인쇄돼 나가면 되돌릴 수 없다.
2026-09-11에는 이렇게 확인했다(파이썬 `qrcode` 로 만들고 `cv2.QRCodeDetector` 로 되읽기):

```
읽어낸 주소: 'https://korea-street.com/seoul/jongno-gu/'
원래 주소  : 'https://korea-street.com/seoul/jongno-gu/'   ✅ 같다
```

⚠️ QR은 **CDN 스크립트로 그리지 않는다.** SVG 를 파일 안에 박아 넣는다 —
인쇄할 때 인터넷이 끊겨 있거나 CDN 이 막히면 **빈 네모가 찍힌다.**

## 🚨 일부러 안 넣은 것 — 이 칸이 제일 중요하다

| 안 넣은 것 | 왜 |
|---|---|
| 입장료·**무료 여부** | 우리 자료에 없다. "무료"라고 적었다가 아니면 손님이 헛걸음한다 |
| 영업시간·휴무일 | 자주 바뀐다. **종이는 한 번 뽑으면 1년을 굴러다닌다** |
| 소요시간·난이도 | 확인한 적이 없다 |

**바뀌는 것은 전부 QR 뒤로 보낸다.** 종이에는 잘 안 바뀌는 것만 —
이름 · 동네 · 가장 가까운 역.

### ⚠️ 만들다가 실제로 당한 것

초안에 북악산 옆에 **「Bring ID — part of the trail is a controlled zone」**이라고 적었다.
**우리 자료에 없는 문장이고, 내가 지어낸 것이다.** 게다가 북악산은 2022년에 전면
개방돼서 지금은 틀린 말일 가능성이 크다. 화면을 눈으로 보다가 잡아서 뺐다.

**종이는 화면과 다르다 — 고쳐도 이미 뿌린 것은 못 고친다.**
전단에 한 줄을 넣을 때마다 "이게 우리 자료 어디에 있나"를 물을 것.
자료에 없으면 **비워 둔다**(북악산은 결국 「청운동」만 적었다).

## 다음 동네를 만들 때

지금은 손으로 만든 HTML 한 장이다. 두세 장까지는 그게 빠르다.
**네 장째부터는** `dist/seoul/<구>/index.html` 과 `src/data/nearest-station.json` 에서
뽑아 찍는 스크립트를 만드는 게 낫다.

자료가 어디 있는지:

```
곳 이름·갈래   dist/seoul/<구>/index.html   (빌드 뒤에 생긴다)
가까운 역·거리  src/data/nearest-station.json  → 곳[<id>].station / .dist
id → 슬러그    src/data/place-slugs.json
짐 보관 지점    src/lib/luggageFacts.ts 의 OFFICIAL_BRANCHES
```

⚠️ **가까운 역이 없는 곳이 있다**(산·둘레길). 그런 곳은 역 줄을 비우고
법정동만 적는다 — 없는 역을 지어내지 않는다.

### 어느 동네부터

게스트하우스가 많은 순서로: **마포구(홍대)** → 용산구(이태원) → 종로구(끝남) → 중구(명동).
다만 **한 장을 먼저 들고 나가 반응을 보고** 나머지를 만드는 편이 낫다 —
안 쓰는 종이를 열 장 만드는 것이 가장 아까운 일이다.
