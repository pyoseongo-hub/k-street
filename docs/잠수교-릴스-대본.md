# 🌉 잠수교 릴스 대본 — 30초

사장님 (2026-09-15):

> *"이거는 미끼야. 조금 과장되게 감성 자극."*
> *"대본이 이게 뭐야 엉망이네. 뭔가 **말하듯이** 하는 게 아니라…"*

🚨 **첫 판은 대본이 아니었다.** 컷마다 영어 문구를 하나씩 박아 놓은 **표**였다 —
「Seoul closes a bridge.」 「100 food trucks.」 「One bridge.」…
따로 떼어 놓으면 그럴듯한데 **이어서 읽으면 말이 안 된다.** 순서도 거꾸로였다
(트럭 백 대를 먼저 말하고 다리를 나중에 말한다).

문구를 모아 놓는다고 대본이 되지 않는다. **한 사람이 처음부터 끝까지 말해야** 대본이다.
그래서 **말을 먼저 쓰고**, 그 말에 사진을 붙였다.

---

## 🗣️ 말 — 이게 대본이다

소리 내어 읽어 보면 이어진다. **이 순서와 말투를 지킨다.**

```
일요일엔 이 다리에 차가 안 다녀요.

대신 푸드트럭 백 대가 들어와요.

한강 위에서, 서서 먹어요.

해가 지면 다리 아래로 물이 쏟아지는데
거기에 불이 켜져요.

그때부턴 아무도 안 일어나요.

10월, 일요일마다. 공짜예요.
```

말이 여섯 마디다. **다리 → 트럭 → 먹는다 → 해 진다 → 안 일어난다 → 언제.**
앞이 뒤를 끌고 간다 — 첫 판에는 이게 없었다.
