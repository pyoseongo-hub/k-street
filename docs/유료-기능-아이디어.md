# 💳 유료 기능 — 아이디어 장부 (2026-09-12)

> 사장님:
> "스트릿 푸드 지금 기능 무료로 하고 사용자 늘면 추가기능을 만들어 사용자 유료화하고 싶은데
> **두 앱 합쳐서 3,000원 30일 사용권**.
> 추가기능 받기 위해서 **의미있는 기능**이어야 하는데 아이디어 만들어 저장"

**아직 만들지 않는다. 언제 시작하는지는 맨 아래 §6 에 숫자로 박아 뒀다.**

---

## 1. 🚨 먼저 — 넘으면 안 되는 선 네 개

이걸 안 정하고 기능부터 고르면, 돈은 벌리는데 앱이 망가진다.

### ① 지금 무료인 것을 **나중에 잠그지 않는다**

우리는 **이미 「평생 무료」라고 적어 두고 내보냈다.** 두 자리다:

| 어디 | 문구 |
|---|---|
| 앱 화면 | `freeNoSignup` = 「평생 무료 · 가입 없음」 |
| **곳 페이지 3,708장**(12개 언어) | 「K-Street — 서울 동네를 12개 언어로 안내합니다. **평생 무료, 가입 없음.**」 |

그래서 **저장 개수 제한 · 광고 제거 · 언어 잠그기 같은 방식은 쓸 수 없다.**
그건 약속을 깨는 것이고, 손님은 그걸 정확히 알아본다.

✅ **사장님 구조가 이 문제를 이미 풀었다** — *"지금 기능 무료로 하고 **추가기능**을 만들어"*.
지금 있는 것은 그대로 두고, **새로 만든 것**만 유료로 한다. 그러면 약속을 안 깬다.

⚠️ 다만 문구는 손봐야 한다. 유료가 붙는 날:
```
전  평생 무료 · 가입 없음
후  지금 있는 기능은 평생 무료 · 가입 없음
```
**「평생 무료」를 통째로 지우면 안 된다.** 지금까지 쓰던 손님에게는 여전히 사실이다.

### ② **노출을 팔지 않는다** (케이푸드 초심 ①)

식당·장소가 돈을 내고 위로 올라가는 일은 없다.
*"쓰는 순간 이 앱이 존재할 이유가 사라진다."* 유료 기능은 **손님이 손님 자신을 위해** 사는 것이다.

### ③ **정확도를 깎지 않는다**

「유료 회원만 정확한 값」 같은 것은 없다. 틀린 정보를 무료에 주는 셈이 된다.

### ④ **고정비를 올리는 기능은 계산부터** (케이푸드 초심 ③)

지금 두 앱 고정비:

| | 월 |
|---|---|
| 케이푸드 (Render Starter + 도메인) | 11,500원 |
| K-Street (GitHub Pages 무료 + 도메인) | 약 1,250원 |
| **합계** | **약 12,750원** |

서버가 필요한 기능을 넣으면 이 숫자가 오른다. **오르면 손익분기도 같이 오른다.**

## 2. 💰 3,000원 / 30일이 말이 되는가 — 계산

### 손님 쪽
방한객은 보통 **5~10일** 머문다. 30일권이면 **여행 전체를 덮는다.**
3,000원은 **커피 한 잔의 3분의 1**이고, 편의점 삼각김밥 두 개 값이다.
외국인에게는 약 **$2**다 — 망설일 금액이 아니다. 가격은 잘 잡으셨다.

### 우리 쪽

| 파는 길 | 수수료 | 실수령 |
|---|---|---|
| 웹 결제(PWA) | PG 약 3% | **약 2,910원** |
| 구글플레이 인앱결제 | 15%¹ | 약 2,550원 |

¹ 구글·애플 모두 소규모 개발자는 15%다. **쓰기 전에 그해 기준을 다시 확인할 것** — 정책이 바뀐다.

**K-Street 은 PWA 라 웹 결제를 붙일 수 있다.** 수수료가 5분의 1이다. 이게 우리 구조의 장점이다.

### 손익분기

```
고정비 12,750원 ÷ 실수령 2,550원 = 월 5명
```

**월 5명이면 두 앱 고정비를 다 덮는다.**
무료 앱의 유료 전환율은 보통 1~3%다. 2%로 잡으면 **설치 250개**면 넘는다.

⚠️ **그런데 이 계산에 안 들어간 비용이 있다** — **사장님 시간**이다.
결제를 붙이려면 통신판매업 신고·PG 심사·환불 처리·문의 응대가 따라온다.
사장님은 직업이 있으시고 쉬는 틈에 이 일을 하신다. 그 시간이 진짜 비용이다.
📌 그래서 §6 의 시작 조건을 **설치 250개가 아니라 1,000개**로 잡았다.

💡 **통신판매업 신고는 이미 해 보셨다** — 메모짱 때 만든
[통신판매업 신고 서류](https://claude.ai/code/artifact/fe412d3a-6f2c-4d17-8aa8-f723ea197f9e) 아티팩트가 남아 있다.
그때 겪은 절차를 그대로 쓰면 된다.

## 3. ✅ 추천 세 가지 — 셋 다 고정비 0원

고른 잣대: **① 손님의 진짜 고통인가 ② 우리만 할 수 있나 ③ 고정비가 0인가
④ 지금 있는 걸 안 잠그나**

### 🥇 1. 오프라인 꾸러미 — 「데이터 없이도 다 보인다」

관광객이 실제로 겪는 가장 큰 불편이다:

- 유심·로밍 없이 다니는 사람이 많다 (공항 와이파이만 믿고 온다)
- **지하철 지하에서 끊긴다** — 정작 길을 찾아야 하는 순간이 거기다
- 데이터가 있어도 아껴 쓴다

**무엇을 담나:** 고른 구의 곳 전부 — 이름·사진·주소·가장 가까운 역·
**택시 기사에게 보여 줄 한국어 카드**·짐 보관함 위치. 케이푸드 쪽은 그 동네 맛집과 메뉴.

**왜 우리가 잘하나:** K-Street 은 **PWA** 다. Service Worker 가 이미 깔려 있어서
**절반은 이미 만들어져 있다.** 새 서버가 필요 없다.

**고정비:** 0원. 손님 폰에 저장하는 것이라 우리 쪽 비용이 없다.

⚠️ **확인할 것:** 사진 용량. 309곳 사진을 통째로 담으면 수백 MB가 될 수 있다.
**구별로 쪼개서** 「오늘 갈 구만」 받게 하면 된다. 만들기 전에 실제 용량을 재 볼 것.

### 🥈 2. 축제 확정 알림 — 「날짜가 나오면 알려 드립니다」

**오늘(2026-09-12) 만든 것의 바로 다음 칸이다.**

우리는 이제 **구청이 올린 확정 날짜를 매일 받는다**(`docs/축제-날짜-구청에서-받기.md`).

**왜 우리만 할 수 있나:** 구청 자료를 매일 받아 12개 언어로 보여 주는 앱이 우리뿐이다.

  **서버가 전혀 필요 없다** — 파일 한 장 만들어 주는 것뿐이다.

### 🥉 3. 두 앱을 잇는 「하루 계획」

**사장님이 가격을 「두 앱 합쳐 3,000원」으로 잡으신 이유가 여기서 살아난다.**
따로 쓰면 두 앱이지만, **합쳤을 때만 생기는 값**이 있어야 그 가격이 말이 된다.

> 오늘은 **종로**. 광장시장(케이푸드) → 인사동 문화의 거리(K-Street) →
> 익선동 한옥골목 → 저녁은 근처 노포. **거리순으로 이어서.**

**자료는 이미 다 있다:**
- 두 앱 다 **법정동 단위** — 이어 붙일 열쇠가 같다
- 두 앱 다 **12개 언어**
- K-Street 은 어제 만든 **거리순 보기**(`districtDistance.ts`)가 있고,
  케이푸드는 **가까운 역** 자료가 있다

**고정비:** 0원. 양쪽 자료를 화면에서 합치는 일이다.

⚠️ **먼저 풀어야 할 것:** `docs/다음-앱-아이디어.md` §「두 앱을 잇는 법」에
적어 둔 **무료 급식소 문제**다. 이 유료 구조가 그 답이 된다 —
**두 앱 다 지금 기능은 무료**고, 유료는 **합쳐서 새로 만든 것**뿐이다.
어느 쪽에서 넘어와도 잠기는 문이 없다.

## 4. 🚫 지금은 안 하는 것 — 왜 뺐는지 적어 둔다

| 아이디어 | 왜 아닌가 |
|---|---|
| **저장 개수 제한 · 광고 제거** | **지금 있는 걸 깎는 방식**이다. 「평생 무료」 약속을 깬다 (§1-①) |
| 메뉴판 **사진 번역** | 사진 한 장마다 **원가가 붙는다**. 게다가 **구글 렌즈가 공짜로** 한다 — 이길 자리가 아니다 |
| **알레르기·채식 카드** | 틀리면 **사람이 다친다.** 병원 야간진료와 같은 칸이다. 확인 체계를 갖추기 전엔 손대지 않는다 |
| **「지금 문 여는 곳」** | 영업 여부는 **확인이 어렵다.** 틀리면 헛걸음하고, 그게 유료라면 더 나쁘다 |
| **노출·순위 판매** | 케이푸드 초심 ①. 논의 대상이 아니다 |
| 숙소·항공·투어 **예약 수수료** | 남의 재고를 파는 일이라 **우리 자료가 안 쓰인다.** 판이 다르다 |

## 5. 🧩 유료로 **가르는 자리**를 어떻게 정하나

같은 기능도 어디서 자르느냐에 따라 인색해 보이기도, 후해 보이기도 한다.

| ❌ 인색한 자름 | ✅ 후한 자름 |
|---|---|
| 하루 3곳까지만 보기 | 다 보여 준다. **오프라인으로 갖고 나가는 것**만 유료 |
| 번역 5개 언어까지만 | 12개 다. **캘린더로 받는 것**만 유료 |
| 코스 1개만 저장 | 다 저장. **두 앱을 합쳐 짜는 것**만 유료 |

📌 **잣대 한 줄:** 「무료 손님이 **뭔가를 빼앗겼다고 느끼면** 잘못 자른 것이다.」
유료는 **더 주는 것**이어야지, **덜 주는 것**이면 안 된다.

## 6. 📅 언제 시작하나 — 숫자로 박아 둔다

**지금은 아니다.** 사장님도 *"사용자 늘면"*이라고 하셨다.

```
지금 설치 수:  거의 0    (K-Street 은 2026-09-10에야 검색에 등록됐다)
시작 조건:     설치 1,000개
```

**왜 1,000개인가:** 고정비만 보면 250개면 넘는다(§2). 그런데 결제를 붙이는
**사장님 시간**이 계산에 안 들어가 있다. 그 시간을 쓸 값어치가 나오려면
고정비의 네 배쯤은 돼야 한다.

**그전까지 할 일은 하나다 — 손님을 만드는 것.**
`docs/다음-앱-아이디어.md` 에 적어 둔 그대로다:

> 지금 우리에게 **없는 것은 만들 능력이 아니라 사람의 눈**이다.

⚠️ **케이푸드는 10월에 마무리된다.** 그전에는 이 이야기를 진행하지 않는다.
