# 🚕 택시 — 무엇이 되고 무엇이 안 되나

**2026-09-04.** 사장님 지시로 시작했다:

> "택시는 스트릿에서 카카오 택시 바로연결 하게 하는게 좋겠는데 / 요즘 수도으로 택시 못잢어"

맞는 말이다. 요즘 서울에서 길에서 손 들어 택시를 잡기는 어렵고, 대부분 앱으로 부른다.
그런데 **앱으로 넘기는 길이 실제로 있는지**를 먼저 확인해야 했다.
검색 요약만 보고 "된다"고 적었다가 틀린 적이 있어서, 이번에는 사장님 폰에서 하나씩 눌러 봤다.

---

## 1. 실제로 눌러 본 결과

시험지를 `korea-street.com/taxi-test.html` 에 올려 놓고 눌렀다.
(아티팩트로 먼저 만들었는데 **안전 상자(sandboxed iframe)** 라 `kakaomap://` 같은 앱 주소를
막아서 아무 반응이 없었다 — "이거 안눌려". 시험을 돌릴 수 없는 곳에 시험지를 준 셈이었다.
그래서 우리 도메인의 평범한 웹페이지로 옮겼다.)

| 링크 | 결과 |
|---|---|
| `kakaomap://route?ep=…&by=PUBLICTRANSIT` (지금 앱이 쓰는 것) | ✅ 열린다. 출발·도착 모두 채워진다 |
| `kakaomap://route?ep=…&by=CAR` | ✅ 열리고 출발·도착 채워짐. **그런데 탭이 자동차/대중교통/도보/자전거뿐 — 택시 탭이 없다.** 요금만 "택시 약 39,600원"으로 뜬다 |
| `kakaot://`, `kakaot://taxi`, `kakaot://taxi?dest_lat=…` | ❌ |
| `uber://?action=setPickup&dropoff[…]` | ⚠️ **앱은 열리는데 픽업·도착이 둘 다 비어 있다** |
| `m.uber.com/ul/?…` | ⚠️ 브라우저에서 로그인 화면. 앱에 로그인해 뒀어도 웹 세션은 따로다 |

사장님 정리: **"택시가 없네 자기네 아플끼리 연동을 안시켰네."**

즉 **카카오맵 ↔ 카카오T 사이에도 목적지가 안 넘어간다.** 우리가 못 하는 게 아니라
그쪽이 공개해 둔 길이 없다.

## 2. 그래서 무엇을 했나 — 「기사에게 보여 주기」

남의 앱이 고쳐 주기를 기다리지 않는다.
**손님이 길에서 실제로 겪는 문제**를 다시 보면, "앱에서 택시를 못 부른다"가 아니라
**"기사에게 목적지를 못 대겠다"** 이다. 그건 우리 화면 안에서 지금 풀 수 있다.

길찾기 버튼 아래에 **「🇰🇷 기사에게 보여 주기」** 를 달았다
(`src/components/DriverCard.tsx`). 누르면 화면 전체가 이렇게 바뀐다:

```
        기사님, 여기로 가 주세요

      강북청소년축제

  서울특별시 강북구 도봉로76가길 55 (미아동)

           감사합니다 🙏
   ─────────────────────────────
   Show this screen to your taxi driver
              [ Close ]
```

지킨 것 넷 —

1. **기사가 읽는 부분은 언제나 한국어다.** 손님이 태국어로 앱을 쓰고 있어도
   상호·주소는 한국어 그대로 나온다. 번역되는 것은 버튼 이름과 안내 한 줄뿐이다.
2. **밝은 색으로 고정한다.** 손님 폰이 다크 모드여도 이 화면만은 흰 바탕·검은 글씨다.
   택시 안은 어둡고 기사는 운전석에서 팔을 뻗어 흘끗 본다.
3. **주소를 지어내지 않는다.** 365곳 중 **319곳(87%)** 만 `addr` 을 갖고 있다.
   없는 곳은 `서울특별시 ○○구 ○○동` 까지만 적는다. 틀린 주소로 기사를 엉뚱한 데
   보내는 것이 빈칸보다 훨씬 나쁘다.
4. **목록 카드와 지도 팝업 둘 다에 단다.** 한쪽에만 달면 지도에서 마커를 눌러 들어온
   손님은 이 기능을 영영 못 본다 — 이 저장소가 여러 번 당한 '반쪽 적용'이다.

### 만들면서 걸린 것

- 처음엔 버튼 옆에 그냥 그렸는데 `position: fixed` 인데도 **카드 안에 갇혔다**
  (축제 카드 한 칸 안에서 상호가 옆으로 잘렸다). 조상 중에 `transform` 이 걸린 요소가
  있으면 `fixed` 의 기준이 화면이 아니라 그 요소가 된다.
  → `createPortal` 로 `document.body` 에 그린다.
- 「서울세계불꽃축제」처럼 **띄어쓰기 없는 긴 상호**는 줄바꿈 자리가 없어 화면 밖으로
  나간다. → `overflow-wrap: anywhere`, 글자 크기는 `clamp(30px, 9.5vw, 58px)`.

## 3. 남은 길 — 카카오에 제안

카카오맵에서 택시로 넘어가는 길이 열리면 이 앱뿐 아니라 **모든 외국인 관광객**에게
도움이 된다. 카카오 쪽에도 손해가 아니다(호출이 늘어난다).
🐞 **처음에 내가 틀린 곳을 적어 뒀다.** `with.kakao.com` 을 넣었는데,
사장님이 실제로 열어 보고 짚어 줬다 — **"여기 아닌 거 같어 / 상품에 대한 건데 전부"**.
그 폼은 **선물하기 상품 입점**용이다(칸이 전부 `배송상품(패션)`·`(식품)`·`(디지털/가전)`…).

그리고 더 근본적인 것을 놓치고 있었다:

> 🚨 **카카오T와 카카오맵은 「카카오」가 아니라 「카카오모빌리티」다. 별도 회사다.**

**링크를 눌러 보지 않고 이름만 보고 적어 둔 탓이다** — "확인 못 한 것은 넣지 않는다"를
내가 어겼다. 제대로 된 곳은 이렇다:

| | 어디로 | 왜 |
|---|---|---|
| ❌ | ~~with.kakao.com~~ | 상품 입점 창구. 회사도 다르다 |
| ✅ 1순위 | **tech.partners@kakaomobility.com** | 카카오모빌리티 기술 제휴. **폼이 아니라 이메일** |
| ✅ 2순위 | [devtalk.kakao.com](https://devtalk.kakao.com/) 「카카오내비」 | 공개 게시판. 메일에 답이 없을 때만 |

카카오모빌리티는 개발자용 창구를 따로 갖고 있다 —
[developers.kakaomobility.com](https://developers.kakaomobility.com/) 는 길찾기 API 같은 것을
**제휴 계약을 맺은 곳에만** 열어 준다. 우리가 묻는 종류의 이야기를 **받아 주는 창구가
실제로 있다**는 뜻이다.

제안서 초안은 `docs/카카오-제안서.md` 에 있다.
**개인 개발자 이름으로** 보낸다(사장님 결정 2026-09-04: "사업자 보낼 이유가 있나
개인으로해 개인 개발자"). 사업자를 앞세우면 제휴 심사로 넘어가 오래 걸리고,
우리가 원하는 것은 계약이 아니라 **URL 스킴 하나**다.

## 4. 우버는 어떻게 하나

지금은 **안 넣는다.** 앱은 열리는데 픽업·도착이 비어 있으면 손님은
"이 앱이 고장 났다"고 읽는다 — 아무 버튼도 없느니만 못하다.
우버가 딥링크를 고치거나, 우리가 제휴로 `client_id` 를 받으면 그때 다시 본다.
