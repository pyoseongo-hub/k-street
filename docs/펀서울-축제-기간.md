## 🔎 사람이 봐야 할 후보 (저장하지 않았다)

이름이 비슷하지만 **꼭 맞지는 않아** 안 받은 것이다. 같은 축제가 맞으면
`src/data/festival-dates-manual.json` 에 손으로 적는다 — 이 스크립트는
`name-aliases.json` 을 읽지 않는다(그 표는 관광공사 이름을 잇는 자리다).

```
   「강남 미디어 윈터페스타」(강남구)  ≈  「윈터페스타」(종로구)  2026-12-04
   「공공미술 빛조각축제 <노원 달빛산책>」(노원구)  ≈  「2026 노원달빛산책」(노원구)  2026-10-16
   「카운트다운 부산」(수영구)  ≈  「2027 카운트다운」(마포구)  2026-12-31
```
