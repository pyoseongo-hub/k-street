특히 구글 지도 이야기는 **"길찾기가 아예 안 된다"고 쓰면 틀린 말이다** —
한국에서 구글 지도는 도보·자동차 길찾기가 안 되고 **대중교통은 된다.**

## 📌 올리기 전에 — 인스타는 다르다

| | |
|---|---|
| 🔗 **캡션의 링크는 안 눌린다** | 인스타는 캡션 속 주소를 링크로 안 만든다. **프로필(bio)에 넣고** 캡션에서는 "link in bio" 라고 가리킨다 |
| 👀 **첫 줄이 전부다** | 두 줄쯤 지나면 「... 더 보기」로 접힌다. **첫 줄에 제일 중요한 말**을 넣었다 |
| #️⃣ **해시태그는 최대 30개** | 아래는 15~20개씩이다. 댓글에 따로 달아도 된다 |
| 🖼️ **사진** | `public/screenshots/` 에 앱 화면 3장이 있다. 계절 표지가 오늘 바뀌었으니 **새로 찍는 게 낫다** — `node scripts/make-screenshots.mjs` |
| 🌐 **한 번에 한 언어** | 12개를 한 글에 다 넣으면 아무도 안 읽는다. **언어마다 따로 올리거나**, 첫 줄만 그 언어로 하고 영어를 받쳐 둔다 |

## 🔁 다음에 고칠 때

- **곳 수가 바뀌면** 12군데를 다 고쳐야 한다. `345` 로 찾으면 된다.
- 숫자는 `npx vite build --ssr scripts/count-for-promo.ts --outDir .promo && node .promo/count-for-promo.js` 로 다시 센다.
- 계절이 바뀌면 해시태그의 계절 낱말(단풍 · 紅葉 · 枫叶 · otoño · Herbst …)도 같이 바꾼다.
